## 0. 通用绘制约定（所有占位）

- **描边**：每个占位块带 **≥1px 近黑棕 `#2A1A12`** 描边（高对比轮廓，保证任意背景可读；accessibility §2.2/#1）。
- **朝向**：方向性实体（栗宝/锥冲/嘟浮）绘制朝右，运行时 `flipX`（`facing:1|-1`）实现左右。
- **渲染方式（建议）**：用 `Phaser.GameObjects.Graphics` 运行时绘制——`fillRoundedRect` / `fillCircle` / `fillRect` + `lineStyle(≥1, 0x2A1A12)` 描边；不依赖实际 PNG 文件（E1.S1 即可跑通）。
- **颜色来源**：全部 hex 引用美术圣经 §3 色板；占位与未来正式像素同色，换图集时视觉一致。

## 2. UI 矢量项（提醒工程对齐）

- 渲染层：**矢量 / 运行时系统字体**，**不入像素图集**（混合 UI；ADR-004 / 美术圣经 §7.1 / 08-ui-hud）。
- 清单：生命爱心 `ui_heart`、分数/金币 `ui_coin`、星级 `ui_star`、按钮 `ui_button`、进度条 `ui_progress`。
- 规范：中文 ≥14px 等效（accessibility §2.2/#6）；触控热区 ≥48×48（Basic 强制）；圆角 + 统一描边色 + 共享色板。
- 世界内拾取的 coin/heart 为像素精灵（§1.5），仍在图集；HUD 显示图标为矢量，二者视觉一致即可。

## 3. 占位即可长期项（可长期不补正式像素）

- **视差背景 / 远景**：纯色渐变矩形即可长期占位。
  - 天空层：天蓝 `#5BC8F5` → 暖黄 `#FFD23F` 底部渐变。
  - 远景层（parallax 0.3）：低饱和山丘剪影（草绿降饱和或冷蓝灰）。
  - 中景层（parallax 0.6）：灌木/石块色块（暖橙 `#F2933C` / 草绿 `#7CC242`）。
- 这些层不抢前景辨识度，**可整个项目周期保持占位**，正式美术优先投入游戏内实体（§4）。

## 4. Phase 5 前需补正式像素（P0 正式 优先于 P1）

以下占位**必须在 Phase 5 前替换为正式像素资产**（即 `asset-manifest.md` §4 的 P0 正式清单），优先级高于 P1 动画细化：

| 优先级 | 实体 | 占位 → 正式要求 |
|---|---|---|
| **P0 正式（必须补）** | 栗宝 FULL/SMALL | 完整剪影 + idle/run/jump/hurt 动画 + juice（当前圆角块占位） |
| P0 正式 | 刺栗 / 锥冲 / 嘟浮 / 石炮 | 完整剪影 + 基础动画循环（当前纯色形占位） |
| P0 正式 | 地形 ground / interactive_block | 瓦片集 + 主题换色（草原/洞穴/天空） |
| P0 正式 | 金币 / 爱心 / 元气果 | 浮动 + 拾取动画（当前纯色形占位） |
| P0 正式 | 凯旋之门 | 发光门 + 通关动画（当前拱形矩形占位） |

**P1（可延后，Phase 5 后补）**：锥冲 charge 冲锋循环、敌人踩死/death 动画、道具吞入动画、fx 粒子（尘土/星光 8×8）——这些在占位期用静态帧即可跑通，正式像素阶段再细化。
