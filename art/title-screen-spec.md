# 栗宝大冒险 · 标题屏（TitleScene）视觉增强规格

> 提交角色：美术总监 art-director（团队 title-beautify）
> 关联文档：`src/game/scenes/title-scene.ts`（现状实现）、`art/art-bible.md`（视觉身份与锁色板纪律）
> 交付目标：供主理人汇编后交付工程落地，本文件**仅含美术规格与参数，不含任何 TypeScript 代码**。

## 0. 通用约束（三方案共同遵守）

| 约束项 | 规则 |
|---|---|
| 分辨率 | 逻辑 512×288（16:9），原点左上；CENTER_X=256，底 H=288。所有坐标相对逻辑中心，不依赖 `window`/`document`（微信 `Scale.NONE` 兼容）。 |
| 色彩纪律 | 仅用 **grass biome 锁色板** + art-bible 已定义的**栗宝角色身份色**；不新增任何色值。锁色板：草绿 `#7CC242` / 阴影绿 `#5FA82F` / 描边 `#2A1A12` / 暖橙 `#F2933C` / 暖黄 `#FFD23F` / 命粉 `#F26D8B` / 警示红 `#E8483B` / 经济金 `#F2C94C` / 蓝紫 `#6E7BF2` / 环境冷蓝 `#4A78C0` / 天空 `#5BC8F5`；标题/文字用石灰白 `#F4EFE6`。 |
| 角色色来源 | 栗宝身份色（栗色 `#B5763E` 主体 / 浅色肚皮 `#F0D9B5` / 暖黄 `#FFD23F` 高光）载于 art-bible §4.2，属项目主 ≤64 色板，**非本屏新增**；若主理人要求"标题屏纯 grass biome 锁色板"，栗宝可降级为暖橙 `#F2933C` 主体 + 暖黄嫩芽（偏离角色圣经，需 sign-off）。 |
| 云朵白 | `#FFFFFF` 仅允许用于背景云插画，不计入游戏内资产调色板，未用于任何前景/UI/文字。 |
| 文字描边红线 | 所有 Phaser Text **禁止 stroke / strokeThickness**（微信 CANVAS 文字描边有纹理失败导致不显示的风险），对比度靠暗色衬板或填充色保证。 |
| 几何描边安全 | 纯 Graphics 几何描边（`strokeRect` / `strokeRoundedRect` / `strokeLineShape` 等）走不同渲染路径，**可安全使用**；仅 Text 描边受限。 |
| 字体回退 | 所有 Text 显式 `fontFamily: 'PingFang SC','Microsoft YaHei','Heiti SC','Noto Sans SC',sans-serif`。 |
| 动效/资源 | 全部纯 Phaser tween，零新增位图/音频/字体（ADR-004）。 |
| IP 红线 | 禁用水管工/蘑菇/星星★/旗杆/龟壳等任天堂符号；星点用原创菱形/圆点粒子，凯旋之门用原创发光拱替代旗杆。 |

## A. 现状诊断

当前标题屏功能完整但视觉朴素：标题区仅用半透明纯色矩形衬板，缺乏角色形象与精致装饰，层次仅靠三层山丘的草绿/阴影绿明度差体现，整体"插画感"与 IP 记忆点不足。具体短板：① 无主角栗宝形象，玩家进入游戏前缺少角色认知钩子；② 衬板为无装饰色块，与标题/副标题/按钮的层次割裂、缺乏焦点；③ 装饰元素仅 3 朵云 + 3 层山丘，缺少前景点缀与微动态亮点。

## B. 美化方向（轻量微调 → 较精致，梯度）

### 方向一 · L1「点睛」（轻量微调）

- **定位**：零布局骨架改动，仅对现有元素做对比度与细节补强，落地风险最低。
- **布局坐标**（沿用现状，仅微调）：
  - 标题文字 `(256, 98)`、副标题 `(256, 132)`、按钮中心 `(256, 220)`（150×44）。
  - 云 `(90,46)` / `(392,38)` / `(250,64)`；山丘 baseY `202 / 224 / 246`。
  - 标题衬板上移为不透明暗底：中心 `(256, 112)`，340×86，α 0.55（原 0.45），底部加暖黄高光线 `y=155, x:96→416, h=2`。
- **配色**：仅锁色板——衬板填充 `描边#2A1A12`、高光线 `暖黄#FFD23F`、山丘顶亮边 `草绿#7CC242`（baseY 顶缘 3px 亮草边）、山脚泥地带 `暖橙#F2933C`（最近层底部 4px 暖橙带）。
- **新增装饰元素**：① 三层山丘顶部各加 3px 草绿亮边（强化"可站立"可读性，呼应 art-bible §5.2）；② 最近山丘底部加 4px 暖橙泥土带；③ 标题衬板底部暖黄高光线；④（可选）衬板四角加草绿小圆点角标。
- **动效建议**：云朵横向缓慢漂移（x ±8，4s `Sine.InOut` yoyo repeat -1）；标题入场弹入（scale 0.92→1，`Back.easeOut`，420ms）；按钮维持脉冲（scale 1→1.06，700ms）；山丘保持静态。
- **真机 CANVAS 兼容备注**：衬板为填充暗色（非描边）保证标题对比度；标题/副标题/按钮文字全部无 stroke；暖黄高光线为 Graphics 几何线（非 Text）可安全使用 stroke；无需任何位图。

### 方向二 · L2「角色登场」（中等增强）【推荐】

- **定位**：让主角栗宝立于山丘成为视觉焦点，建立 IP 记忆点，层次明显提升，仍零新增资源。
- **布局坐标**：
  - 标题衬板上移：中心 `(256, 84)`，340×76（y:46–122）；标题文字 `(256, 74)`，副标题 `(256, 104)`。
  - 按钮维持 `(256, 220)`（150×44）。
  - **栗宝立绘**：立于最近山丘（baseY=246）右隆起，脚底 `y≈214`，立绘中心 `(404, 192)`，尺寸 ~34×42（宽 34 / 高 42，对齐 32px 半格），不遮挡标题与按钮。
  - 左侧对称装饰：草丛 + 暖黄小花，脚底 `y≈218`，中心 `(104, 200)`。
  - 云 `(90,40)` / `(392,32)` / `(250,58)`；山丘 baseY `200 / 222 / 244`。
  - 星点粒子：6–8 颗，分布 `x:120–392, y:30–70`，缓慢上浮。
- **配色**：grass biome 锁色板（山丘/草丛/花/星点）+ 栗宝角色身份色（栗色 `#B5763E` 主体 / 浅色肚皮 `#F0D9B5` / 暖黄 `#FFD23F` 嫩芽+高光 / 描边 `#2A1A12` 轮廓）。星点用 `石灰白#F4EFE6` 或 `暖黄#FFD23F`；小花花心暖黄、花瓣 `命粉#F26D8B`（命粉在锁色板内）；草丛 `草绿/阴影绿`。
- **新增装饰元素**：① 栗宝圆润栗形立绘（头顶嫩芽、圆脸大眼、短腮红命粉、短圆手脚），立于右前景山丘；② 左侧草丛 + 命粉小花点缀；③ 6–8 颗原创菱形/圆点星点粒子（非★符号）缓慢上浮；④ 标题衬板改为圆角矩形 + 暖黄细描边（Graphics `strokeRoundedRect`，安全）。
- **动效建议**：栗宝呼吸（scaleY 1→1.04，1400ms `Sine.InOut` yoyo repeat -1）；栗宝眨眼（双眼 Graphics 由圆变线，每 3.2s 闪 120ms，用两态交替或 scaleY 压扁）；标题入场弹入（scale 0.9→1，`Back.easeOut`，460ms，微光 alpha 0.6→1）；星点上浮（y -18，alpha 0.2→0.9→0，2.4s repeat -1，错相位 delay）；云朵横向漂移（±10，4.5s）；按钮脉冲 + 悬停 scale 1.08；副标题轻微浮动（相位错开）。
- **真机 CANVAS 兼容备注**：栗宝为纯 Graphics 绘制（`fillCircle`/`fillEllipse`/`fillRect` + 几何描边），不依赖位图/字体；眨眼用 Graphics 重绘而非精灵帧；文字（标题/副标题/按钮/水印）全部无 stroke，靠暗色衬板；星点为 Graphics 几何，tween 改 position/alpha；衬板/边框用 Graphics `strokeRoundedRect`（几何描边，非 Text 描边，安全）。

### 方向三 · L3「第一幕」（较精致）

- **定位**：构建带"凯旋之门"氛围的微场景，标题屏即叙事开场，视觉最饱满，复杂度最高。
- **布局坐标**：
  - 背景中央偏上：凯旋之门发光拱，拱心 `(256, 150)`，拱宽 ~180（x:166–346），拱顶尖 `y≈70`，拱脚 `y≈210`（门立于中景山丘上）。
  - 栗宝立于门前（拱内），中心 `(256, 178)`，尺寸 ~32×40，面向玩家。
  - 两侧藤蔓柱（替代管道）：左 `(60)`、右 `(452)`，脚 `y=244` → 顶 `y=150`，圆角柱体。
  - 标题衬板：拱上方，中心 `(256, 52)`，300×44（y:30–74），圆角 + 暖黄描边。
  - 按钮：`(256, 250)`（160×42）。
  - 前景草叶：底部两侧掠过，`y≈270`，宽 ≤ 屏宽 8%（遮挡 <10%）。
  - 星雨粒子：标题上方 + 门内涌出，10–12 颗。
- **配色**：grass biome + 栗宝色 + 凯旋之门 `暖黄#FFD23F` / `经济金#F2C94C` 发光（建议以暖黄/经济金为主，避免用蓝紫/互动青作装饰光点以免与游戏内功能语义混淆）；藤蔓柱 `草绿/阴影绿` + `暖橙#F2933C` 描边。（`经济金#F2C94C`、`蓝紫#6E7BF2`、`环境冷蓝#4A78C0` 均在锁色板内，可授权使用。）
- **新增装饰元素**：① 原创凯旋之门（发光拱门，替代旗杆，呼应 art-bible §7.2）；② 栗宝立绘于门前；③ 两侧藤蔓柱（圆角柱体，替代管道，去任天堂符号，呼应 §5.2）；④ 门内/上方星雨光斑；⑤ 前景草叶掠过（克制）；⑥ 边框花边：四角暖黄细线 + 草绿小角（Graphics stroke，安全）。
- **动效建议**：凯旋之门亮起脉冲（拱身 alpha 0.5→0.85，1.8s yoyo repeat -1，光点沿拱缓移）；栗宝呼吸 + 眨眼 + 偶尔挥手（右手 Graphics 旋转 12°，600ms，每 5s）；门内光斑涌出（粒子从拱心上升，alpha 渐隐）；星雨慢速上浮（<3Hz，低对比，防光敏）；云朵视差漂移（远云慢/近云稍快，差 ≤0.3 防晕动）；标题弹入 + 暖黄微光；按钮脉冲 + 悬停放大；前景草叶缓慢横移（parallax 1.2，可关）。
- **真机 CANVAS 兼容备注**：拱门/藤蔓/边框/草叶均为 Graphics 几何（含几何描边，安全）；光斑为 Graphics 圆点 tween；文字零描边靠衬板；同屏粒子 ≤ 12 颗（远低于 art-bible §8 同屏 ≤60 预算）；开启"减少动态"开关时关闭前景草叶、星雨改静态（呼应 §9.3）。复杂度高，建议分两期落地（先门+栗宝，后前景/粒子）。

## C. 推荐方案

**推荐方向二 · L2「角色登场」。**

理由：
1. **视觉提升显著**——引入栗宝立绘建立最强 IP 记忆点；左草丛右角色的平衡构图 + 星点粒子 + 圆角暖黄描边衬板，层次与精致度远超现状，但不过度。
2. **锁色板纪律**——仅用 grass biome 锁色板 + art-bible 已定义栗宝身份色，零新增色值。
3. **真机稳定**——栗宝为纯 Graphics 绘制、文字零描边靠衬板、动效全 tween，完全规避微信 CANVAS 文字描边失效风险。
4. **零新增资源**——满足 ADR-004，工程落地成本与现状持平（仅增 Graphics 绘制 + tween 参数）。

对比：L3 更饱满但复杂度/调试成本陡增、装饰语义易与游戏内功能色混淆；L1 提升有限，未解决"缺角色"核心短板。L3 的凯旋之门/藤蔓柱可作为后续版本（Version 2）增强项，本期可选采纳其"圆角暖黄描边衬板"与"星点"作为 L2 的微调补充。

## D. 落地验收清单

### 通用（三方案）

- [ ] 逻辑分辨率固定 512×288，所有坐标相对逻辑中心，不依赖 `window`/`document`（微信 `Scale.NONE` 兼容）。
- [ ] 颜色仅含 grass biome 锁色板 + 栗宝角色身份色（栗色 `#B5763E` / 浅色肚皮 `#F0D9B5` / 暖黄 `#FFD23F`）；无任何锁色板外色值（审计 grep 十六进制）。
- [ ] 云朵白 `#FFFFFF` 仅出现于背景云 Graphics，未用于任何前景/UI/文字。
- [ ] 所有 Phaser Text 显式字体回退 `'PingFang SC','Microsoft YaHei','Heiti SC','Noto Sans SC',sans-serif`；无 `stroke` / `strokeThickness`。
- [ ] 标题/副标题/按钮文字靠暗色衬板或填充色保证对比度（亮度对比 ≥ 3:1，关键交互 ≥ 4.5:1）。

- [ ] 无任天堂符号：无水管工/蘑菇/星星★/旗杆/龟壳；星点用原创菱形/圆点，凯旋之门用原创发光拱。
