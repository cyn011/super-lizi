## 0. 范围与锁色板（红线基准）

本 biome 仅负责**星界（astral）主题视觉**、**四类通用敌（gu_bao / ci_li / du_fu / shi_pao）的星界换皮**、**栗宝羽降（glide）形态的视觉描述（A4）**与**亮底敌人可读性专项（A5）**；玩法 / 数值 / 物理（glide 的 maxFall 条件钳制、投掷、碰撞、可踩语义）由 GDD 与工程负责，**本 biome 仅提供视觉规格，不改任何机制语义、不写代码**。

> ### ⚠️ 关键美术决策（提请主理人知悉）
> **astral 的破局点不是色相，是明度。** design-strategist 的跨 12 biome 明度审计（level-3-1-design.md §3.2）确认：现有 12 个 biome 的地面主面（`rockFace`）全部落在**中—暗**明度带，「高明度地面」是 0 新增 hex 条件下唯一未被用掉的维度。
> **故 astral 做全 biome 唯一的「明度翻面」**：**星白浮岩 `#BEC4F9` 作地面主面（全 biome 唯一亮地面，识别锚点）+ 墨蓝星空 `#1F2244` 作天空（全 biome 最暗天）**，地比天亮、暗元素刻在亮底上——与 volcano（黑岩亮边）恰好互为镜像。二者对比 ≈ **10:1**，远超 WCAG AA。全部关键 hex 由锁色板 `#6E7BF2` 的 tint/lighten 派生，**0 新增**。本人以 art-director 身份**采纳并锁定** design-strategist 建议的 `#1F2244` / `#BEC4F9` 两个签名派生色。
> **与 storm_sky 的硬区分**（同为蓝紫系）：storm_sky = 中明度蓝紫地面 `#6E7BF2` + 中明度冷蓝阴天；astral = 高明度 tint 地面 + 极暗星空，**明度带完全错开**，且装饰语言（点状星屑/星云带 vs 风暴浮岛）全异，不撞。

## 2. 瓦片调色板规则（复用 base 集 + runtime tint · 星界游戏层）

- **复用 1 份 base 瓦片集**，结构/功能语义不变（`ground_top` / `ground_fill` / `oneway` / `interactive_block`）；astral 经 theme palette 映射（§1.2）生成，**不另绘星界瓦片集**（守 ADR-004）。
- **功能语义不变**：solid / oneway / 可踩判定与全部前序 biome 一致；仅主色翻为星白浮岩 `#BEC4F9`。
- **平台顶缘暗边（可站立信号 · volcano 反转）**：volcano 是「黑岩 + 亮顶缘发光边」，astral 严格反过来——**亮岩 + 暗顶缘边**：solid 顶面绘 **1–2px 蓝紫 `#6E7BF2` 暗边 + 外 1px 描边黑 `#2A1A12`**。同一套「顶缘 = 可站立」的形状语言、相反的明度读法，玩家迁移零成本；暗边 vs 星白面对比 ≈ 4.9:1（≥4.5:1 关键交互达标），色盲安全（形状 + 明度双编码，非色相依赖）。
- **浮岩剪影（形状语言，无新色）**：地形从「连绵地壳」改为**离散菱形浮岩块**——底面收窄成**倒棱台**，底缘叠深空影 `#101A2A` 渐隐，强调「悬空」（对齐简报 A3）。云海地面（ty7,8 全宽 solid）视觉处理为「云海层」：星白浮岩面 + 顶缘暗边 + 表面 2–3 道 `#BDE9FB` 云纹横带（deco 换皮，碰撞语义不变、不挖坑）。
- **节拍平台（beatPlatforms）视觉与渲染红线**：astral 下节拍平台沿用星白浮岩面 + 顶缘暗边（同 solid）；初始态 `ghost` = 半透星白（alpha ≈ 0.35）+ 星辉青 `#5BC8F5` 微光边，实体化后转满不透明 + 顶缘暗边清晰。**⚠️ 关卡侧红线（level-3-1-design.md §8）：所有节拍平台瓦片必须位于 `ty=4`（y=128），严禁 `ty=5`。** 本关仅 1 簇 `bp_a1`（tx38,39,40）。视觉呈现须确保 ghost 态星辉边与墨蓝星空 ≥3:1 对比、实体态顶缘暗边与星白面 ≥3:1 对比。
- **interactive_block（✦ 互动块）**：星白浮岩底 + 互动青系 `#5BC8F5` 外发光 + 中心「✦」+ 描边黑（互动语义不变，仅换皮）。
- **主题独有装饰（另绘少量，MVP 全 Graphics 占位，非碰撞）**——全部为**点/带**语言，区别于 cave 柱状 / volcano 裂隙 / vine 藤蔓 / sea 波纹：
  - `deco_star` 星屑：天空/远景散布的 1–2px 亮点（星辉青 `#5BC8F5` 为主、星屑暖黄 `#FFD23F` 零星点缀），≤2Hz 极缓明灭。
  - `deco_nebula` 星云带：远景低 alpha（≤0.18）横向柔带，星云雾 `#BDE9FB` + 蓝紫 `#6E7BF2` 双色层叠，静态或极慢漂移。
  - `deco_dust` 星尘缓升粒：前景/游戏层缓慢上升的微粒（`#FFD23F` 亮部 + `#8C7422` 暗部），密度低、≤2Hz 生成。
- **IP**：浮岩 / 星屑 / 星云为原创天体形态，非星星道具 / 彩虹路 / 任何任天堂符号（「✦」为项目既有互动标记，沿用）。

## 3. 五层视差背景构成（星界 astral）

> 对齐现有 biome 的 5 层范式（天空 / 远景 / 中景 / 游戏层 / 前景）。每层给出：内容 / 构成元素 / 运动·相位建议 / **Reduce Motion 冻结首帧要求（光敏安全 ≤3Hz）**。

**氛围意图（3-1 开篇《浮空初息》）**：Ch2 的「重、热、逼仄」在开篇被彻底翻面——墨色星空、苍白浮岩、稀疏星屑、缓慢星云，靠**高明度地面 + 极暗天空的明度翻面**制造「轻、冷、开阔」的新维度第一口空气（对齐 level-3-1-design.md §2 段 2 与 §2.1 tertiary 定位；与 volcano「暗底亮元素」互为镜像：astral 是**亮底暗元素**，前景/背景明度关系整体倒置）。

**光照**：高环境光、地面自亮（星白浮岩像被星光浸透，是画面最亮的大面）；天空极暗、装饰皆为微光点缀；任意前景元素与相邻背景亮度对比 ≥3:1（关键交互 ≥4.5:1）——本 biome 天然满足：`bg #1F2244` vs `rockFace #BEC4F9` ≈ **10:1**。亮底上的暗元素（敌人 / 顶缘边 / 描边）承担分离职责（专项见 A5）。

### 3.1 五层明细

| 层 | parallax | 内容 | 构成元素（锁色板 / tint） | 运动 / 相位建议 | Reduce Motion / 光敏（≤3Hz） |
|---|---|---|---|---|---|
| **天空** | 0（scrollFactor 0） | 墨蓝星空 + 缓慢星云 | `bg = #1F2244`（墨蓝，tint）满铺；`deco_star` 星屑散点（`#5BC8F5` 为主 + 零星 `#FFD23F` 暖点）；1–2 道 `deco_nebula` 星云带（`#BDE9FB`/`#6E7BF2`，alpha ≤0.18） | 星空静态；星屑 ≤2Hz 极缓明灭（错相，任一时刻 ≥80% 星屑恒亮）；星云极慢横漂 | 星屑停明灭（恒亮首帧）；星云冻结首帧 |
| **远景** | 0.3 | 浮岛剪影群 | 蓝紫 `#6E7BF2` 剪影浮岛（低饱和、无描边），底缘 `#101A2A` 渐隐收窄（倒棱台剪影） | 静态 / 极慢垂直微浮（幅度 ≤2px、周期 ≥4s ≈ 0.25Hz） | 垂直微浮停，固定首帧 |
| **中景** | 0.6 | 星环 / 光带 | 星辉青 `#5BC8F5` 细弧光带（星环，alpha ≤0.3）+ 星云雾 `#BDE9FB` 柔带；零星 `#FFD23F` 暖星点 | 光带极缓流动（相位偏移，≤1Hz）；暖星点 ≤2Hz 缓闪 | 光带停流（冻结首帧）；暖星点停闪 |
| **游戏层** | 1.0 | 浮岩平台 / 云海地面 / 敌 / 道具 / 主角 | `rockFace #BEC4F9` 浮岩 + 顶缘 `#6E7BF2` 暗边 + `#2A1A12` 描边；底缘 `#101A2A` 悬空影；云海地面加 `#BDE9FB` 云纹；敌/道具见 §4 与 A5 | 平台静态；云纹极缓横漂（≤0.5Hz）；羽降缓降尘见 A4 | 云纹冻结首帧；缓降尘密度减半 / 停 |
| **前景** | 1.2（克制，遮挡 ≤10%） | 星尘粒子 / 流光 | `deco_dust` 星尘缓升粒（`#FFD23F`+`#8C7422`）；偶尔一道 `#5BC8F5` 斜向流光（细线，单次 ≤0.2s，间隔 ≥2s） | 星尘缓升（≤2Hz 生成）；流光低频偶发（等效 ≤0.5Hz） | 星尘停生成 / 密度减半；流光禁用 |

**大气叠层（depth 5，可选）**：星辉雾 `#BDE9FB` alpha ≤0.08 全屏极轻叠（顶部略浓、底部透明），塑造「稀薄高空」。**Reduce Motion 下转纯静态低 alpha。**

### 3.2 光敏安全红线（全层统一）

- 所有脉动 / 明灭 / 流动频率 **< 3Hz**（星屑 / 星云 / 光带 / 暖点均 ≤2Hz；流光单次 ≤0.2s、不连续）。
- 单次高亮 ≤0.2s、不连续 >1s；无全屏高频闪；星屑明灭错相、无同步集体闪烁。
- **Reduce Motion 开关开启**：所有动态（星屑明灭 / 星云漂移 / 光带流动 / 星尘 / 流光 / 云纹 / 浮岛微浮）**冻结首帧或密度减半**，仅保留静态构图（对齐 art-bible §9.3）。

## 4. 障碍矩阵：主题键 `astral` 的四类敌换皮

> **仅换皮、不改任何投掷 / 碰撞 / 可踩语义。** 四类敌的几何、行为、判定、y 契约（gu_bao=224 / ci_li=200 / du_fu=120 / shi_pao=100）沿用各自 GDD 与原 biome-spec；本节只定义星界主题下的**视觉重着色**。配色全部锁色板内（§0），形状 + 颜色双编码，色盲安全。**亮底可读性专项处理见 A5（本 biome 与全部前序 biome 的关键差异）。**

### 4.1 换皮一致性要点

- **形状优先**：四类敌剪影（垂直苞 / 圆球 / 扁圆+翅 / 方块+炮口）在星界下**完全不变**，仅重着色 + 星界纹理（脉纹 / 拖尾 / 暗斑 / 星辉口）；颜色为辅、形状为主，色盲安全。
- **亮底反转原则（本 biome 特有）**：前序 12 biome 均为「中—暗底 + 亮敌提亮」；astral 是「亮底 + 敌体压暗」——地面敌（gu_bao / ci_li / shi_pao）主体一律取暗 tint（`#373D79` / `#101A2A`），在星白浮岩上以**暗剪影**成立（对比 ≥4.5:1）。详见 A5。
- **跨关辨识**：du_fu 保持蓝紫主体（全局敌身份）；ci_li 的圆+刺、shi_pao 的方+炮口、gu_bao 的垂直苞轮廓全部不动，不改变任何判定盒。
- **危险双编码**：所有不可踩 / 危害部位（gu_bao 刺、ci_li 刺、shi_pao 炮口缘与弹丸）一律警示红 `#E8483B` + 尖角形状，绝不靠单色。
- **S4 弹幕走廊可读性**（level-3-1-design.md §4.5 反向教学段）：shi_pao 弹丸的 `#E8483B` 芯 + `#5BC8F5` 拖尾在墨蓝星空带（y≈100 弹道高度多为天空背景）对比 ≥4.5:1，保证「滞空 = 暴露」的风险清晰可见——弹道可读性是反向教学成立的前提。
- **IP**：星苞 / 流星体 / 光精灵 / 星炮为原创天体·星界形态，非龟壳 / 星星道具 / 任何任天堂符号。

## A4 · 栗宝羽降（glide）薄翼形态（供 character-team 后续绘制）

> 上游：level-3-1-design.md §2 段 3（「嫩芽被气流吹得张开成一对薄翼」）与 §13.2 A4。**复用 1-1 起就有的头顶嫩芽（art-bible §4.2）作为翼的来源——零新角色资产、零 IP 风险**（非斗篷 / 非羽毛帽 / 非狸猫尾，避任天堂滑翔符号）。机制（maxFall 条件钳制、`glideActive` 信号）归 character-controller / 工程，**本节只定义视觉**。

### A4.1 形态定义

- **来源与位置**：头顶嫩芽的两片子叶**向左右水平展开**，各拉长为一片**薄叶翼**——单翼约 10–12px 长、3–4px 厚，翼根仍连在芽点（头顶），整体像一枚「旋翼种子（枫树翅果）」的原创变体。栗宝身体、脸、肚皮、四肢**全部不变**。
- **配色（锁内，0 新增）**：翼面芽绿 `#7CC242` + 翼缘/翼脉阴影绿 `#5FA82F` + 1px 描边黑 `#2A1A12`；翼尖 1px 星屑暖黄 `#FFD23F` 辉光点（星界气流「浸」在翼尖的微光，克制、不发光晕染）。
- **姿态**：羽降中栗宝身体微前倾（≈5°，可用 sprite 旋转实现，不必新帧）、四肢自然下垂；翼面在头顶撑开如伞。
- **缓降尘**：羽降激活期间，脚下每 0.5–0.8s 逸出 **1–2 粒**星屑缓降尘（`#FFD23F` 亮粒 + `#8C7422` 暗粒，≤3×3px，0.4s 上飘消散）——频率等效 ≤2Hz，光敏安全；Reduce Motion 下停。

### A4.2 帧规格（供 character-team 排期，MVP 不阻塞）

| 帧 | 内容 | 帧数 | 触发 |
|---|---|---|---|
| `glide_open` | 嫩芽两叶「啪」地弹开展平（squash→stretch） | 2 帧（约 0.1s） | `glideActive` false→true |
| `glide_loop` | 翼面微幅上下浮摆（±1px，周期 ≥0.6s ≈ 1.7Hz，<3Hz 安全） | 2 帧循环 | glide 持续 |
| `glide_close` | 双叶收拢回嫩芽原状 | 1 帧（约 0.07s） | `glideActive` true→false（落地/松键/上升） |

- 帧画布沿用栗宝现有规格（32×48 内，art-bible §2.3/§2.5）；命名 `char_mali_glide_open_01/02.png`、`char_mali_glide_loop_01/02.png`、`char_mali_glide_close_01.png`。
- **状态可读性**：翼展开 = 「正在缓降」的形状信号（轮廓变宽 ≈ +20px），玩家与观众一眼可辨，无需 UI 提示——这也是 S1 金币弧无文字教学能成立的视觉前提。

### A4.3 MVP 程序化占位（守 ADR-004，本期落地形态）

- 工程以 `Graphics` 在栗宝头顶绘**两片对称三角/半椭圆翼形**：填充 `#7CC242`、边线 `#5FA82F`、alpha 0.9；`glideActive=true` 时以 2 帧 tween（0.1s）展开、false 时 0.07s 收拢；loop 期 ±1px 正弦浮摆（≤1.7Hz）。
- 缓降尘用既有粒子池（≤2 粒同屏增量，遵守 art-bible §8 同屏 ≤60 粒预算）。
- 真美术帧就绪后按 A4.2 命名一键替换，占位翼形即弃。

## A5 · 亮底敌人可读性专项（重要 · 本 biome 独有问题）

> **问题**：全 12 个前序 biome 的敌人配色都是为「中—暗底」设计的；astral 的星白浮岩 `#BEC4F9` 是全项目第一块亮地面，**中明度敌体的对比会被削弱**（level-3-1-design.md 附录 B·R4 专项）。最严重者为 du_fu（`#6E7BF2` vs `#BEC4F9` 对比仅 ≈2.6:1，低于 3:1 红线）。
>
> **总原则（双管齐下，全部锁内色）**：① **描边加强**——亮底上出现的敌体一律 **2px 描边黑 `#2A1A12`**（较全局 1px 加倍），必要时外缘再加 1px `#101A2A` 深空影软边（等效「暗发光边」，与 volcano 亮发光边镜像）；② **体色压暗 / 内部暗斑**——主体直接取暗 tint，或在体内加锁内暗斑，把「亮底暗剪影」做成 astral 敌人的统一语言。**形状 + 明度双编码，不依赖色相，色盲安全（WCAG ≥3:1，关键交互部位 ≥4.5:1）。**

### A5.1 受影响敌与逐一处理

| 敌 | 原色 vs 亮底 `#BEC4F9` 对比 | 风险 | 处理（锁内，0 新增） | 处理后对比 |
|---|---|---|---|---|
| **du_fu** 光精灵 | `#6E7BF2` ≈ **2.6:1** ❌（最严重） | 飞行轨迹跨亮岩背景时剪影糊 | ① 描边加倍至 **2px `#2A1A12`**；② 肚皮加**深星紫暗斑 `#373D79`**（替代 volcano 的暖黄亮斑——同一「肚斑」形状语言，明度反转）；③ 翅膜用 `#BDE9FB` 半透（与主体分离靠描边而非明度） | 描边 vs 亮底 ≈ **9:1** ✅；暗斑 vs 主体 ≈ 3.2:1 ✅ |
| **gu_bao** 星苞 | 若沿用 volcano 黑苞体 `#2A1A12` 对比足够，但会读作「火山残皮」 | 主题错读（非对比问题） | 苞体改**深星紫 `#373D79`**（vs 亮底 ≈ **5.5:1** ✅）+ 星辉青脉纹提质感；顶刺 `#E8483B` + 2px 描边；软顶 `#FFD23F` 环（vs 苞体 ≈ 5:1，可踩窗口醒目） | ✅ 全部 ≥4.5:1 |
| **ci_li** 流星体 | 警示红刺 `#E8483B` vs 亮底 ≈ 3.5:1（勉强），红球体若沿用则整体偏糊 | 落点精度考核关（S2/S3）需要高可辨 | 主体改**深空影 `#101A2A`**（vs 亮底 ≈ **9:1** ✅）；刺保持 `#E8483B`（刺 vs 暗主体 ≈ 2.6:1，靠**尖角形状 + 2px 描边**双编码补足，非色相依赖）；`#F2933C` 拖尾纹增独特性 | ✅ 剪影 9:1 |
| **shi_pao** 星炮 | 原冷蓝/灰石身在亮底中明度贴近 | 定点炮台须一眼锁定 | 石身改**深星紫 `#373D79`** + 2px 描边；炮口 `#5BC8F5` 星辉（vs 暗石身 ≈ 4.8:1 ✅）+ `#E8483B` 缘 | ✅ |
| （附注）**coin / seed** | `#F2C94C`/`#FFD23F` vs 亮底 ≈ 2.9:1（临界） | 拾取物在浮岩上略糊 | 沿用全局既有描边规范，亮底上确保 **1px `#2A1A12` 描边**渲染开启（现有能力，无新需求）；空中币多处于墨蓝天空背景（y≤184），对比天然 ≥8:1，无虞 | ✅ |

### A5.2 判定规则（给渲染占位与后续真美术的统一口径）

1. **敌体在亮底（`rockFace` / 云海地面）前景出现时**：描边一律 2px `#2A1A12`；主体明度须落在「暗带」（等效 luminance ≤ 0.15，即 `#373D79` / `#101A2A` / `#2A1A12` 档），保证剪影 ≥4.5:1。
2. **敌体在暗底（`bg` 墨蓝星空）前景出现时**（du_fu / shi_pao 弹丸的主要背景）：中明度色（`#6E7BF2`）与亮色（`#5BC8F5`/`#E8483B` 拖尾）直接成立（≥4.5:1），无需额外处理——即 du_fu 的蓝紫主体在天空背景可读、跨到亮岩背景时靠 2px 描边兜底，**双背景均安全**。
3. **危险部位永远红 + 尖角**，可踩窗口永远暖黄 + 发光环——功能色语义全局不变（art-bible §3.2），本专项只动「底色适配」，不动语义色。
4. 色盲模拟自检口径：以上全部依赖**明度差 + 形状**而非色相差（deuteranopia / protanopia / tritanopia 下明度关系不变），Standard 档达标。

## 6. 可访问性（对齐 Standard 分级）

> 目标档位 **Standard**（art-bible §9.4）：色盲双编码内建 + 色盲辅助开关 + 减少动态开关 + 文字尺寸达标 + 防光敏硬底线。本 biome 严格守此档。

- **主题区分（不撞概念/不撞色）**：astral = **星白亮地面 + 墨蓝星空**，是全 13 biome 唯一「地比天亮」的构图；色盲玩家靠**地面明度（唯一高明度）+ 顶缘暗边形态 + 点/带装饰语言（星屑/星云）**即可分辨，零色相依赖。
- **双编码**：可站立 = 顶缘暗边 + 倒棱台形状；危险 = 警示红 + 尖角；可踩窗口 = 暖黄 + 发光环；羽降状态 = 翼展开的轮廓变化（形状信号）——均不靠单色。
- **对比红线**：`bg` vs `rockFace` ≈ 10:1；亮底敌人经 A5 处理后剪影 ≥4.5:1；S4 弹幕在星空背景 ≥4.5:1。
- **静态可读**：所有实体最小显示尺寸 ≥32px 下仅凭剪影判「能否踩」；星屑/星云/光带/流光/缓降尘全部 ≤2Hz（防光敏，硬底线 <3Hz）。
