## 0. 全局约束（所有实体通用）

- **基础网格**：32px 瓦片；内部分辨率 `512×288`（16×9 格）。
- **渲染**：Phaser `pixelArt:true` + `roundPixels:true` + `antialias:false`（美术圣经 §2.3–2.4）。
- **调色板**：全项目共用美术圣经 §3 色板（≤64 色，单 atlas PNG-8 索引色）；本清单所有颜色均引用该色板 hex。
- **朝向翻转**：所有方向性实体**仅绘制朝右单组帧 + 运行时 `flipX`**（依据 `facing:1|-1`，见 GDD 03/04），节省图集。
- **图集工具**：`free-tex-packer` → 输出 Phaser 兼容 atlas JSON（ADR-004）。
- **可访问性基线**：每个像素实体带 1–2px 近黑棕描边 `#2A1A12`（高对比轮廓，accessibility §2.2/#1）；功能色均形状+颜色双编码（美术圣经 §3.2）；每实体提供静态首帧供 Reduce Motion（accessibility §2.2/#8）。

## 2. 逐实体规格

### 2.1 栗宝（char_mali）
- **尺寸**：FULL 画布 `32×40`（w×h）；SMALL 运行时 scale 0.6 → ~`20×24`（不另绘）。
- **帧数 / 动画状态**：
  - `idle` 呼吸：4 帧（±1px 浮动 + 嫩芽摆）
  - `run` 跑动：8 帧（"风火轮"腿循环）
  - `jump` 跳：2 帧（rising / falling）
  - `hurt` 受伤：复用 FULL，iframe 1.5s 闪烁（alpha 切换，无独立帧）
  - SMALL 形态：上述各状态运行时 scale 0.6 渲染
  - 合计绘制帧 ≈ 14（idle4 + run8 + jump2）
- **atlas 归属**：characters 区（主角专属）。
- **碰撞盒**：FULL 画布 32×40 内，AABB `x4,y4,w24,h34`（24×34 居中）；SMALL 同比例 ×0.6 ≈ 14×20。供给 GDD 03/07 的 `sizeScale`。
- **碰撞/画布对齐约定（已锁定）**：**碰撞盒驱动、画布仅为视觉**——物理 `Body` 取 24×34（FULL），SMALL 运行时 ×0.6 → ~14×20；渲染精灵用 32×40 画布并按 `(4,4)` 偏移对齐到碰撞盒原点，缩放时碰撞与精灵同步、不穿地/不悬空。本约定经 engineering-lead 确认（Phase 4 脚手架按此实现），**后续正式像素严格沿用**，避免物理/渲染错位。
- **调色板（引用美术圣经 §3/§4.2）**：主体 栗色 `#B5763E`；浅肚皮 `#F0D9B5`；暖黄高光 `#FFD23F`；嫩芽 草绿 `#7CC242`；腮红（装饰，非功能）`#E89B8B`；描边 近黑棕 `#2A1A12`。
- **朝向翻转**：`flipX`（`facing:1|-1`）。

### 3.2 帧动画表

| 状态 | 帧数 | 说明 |
|---|---|---|
| `idle` 待机 | 2 | 静止轻微呼吸 |
| `detect` 侦测 | 2 | 玩家入 `DETECT_X=160` 且高度差 <48 → 前端楔形尖闪（警示脉冲）、身体前倾（GDD 04） |

| 帧 | 姿态 | 说明 |
|---|---|---|

| 1 | 启动 | 前伸，速度线 ×1 |
| 2 | 冲刺 | 拉长，速度线 ×2 |

| 5 | 复位 | 回帧 0 姿态 |

### 3.3 碰撞盒
- 画布 `48×28`，AABB = `x2, y3, w44, h22`（44×22 居中）。

- 冲锋方向 = `facing`（朝玩家），速度 `CHARGE_SPEED=220`（GDD 04）。

## 4. 占位资产策略（Phase 4 微信最小 demo + 垂直切片）

**原则**：用纯色方块/基础形状 + 正确功能色 + 正确尺寸/碰撞 先过切片；正式像素绘制按优先级排期。占位资产同样遵守功能色正确（双编码基础）、尺寸/碰撞正确、带深色描边保证可读、`flipX` 方向。

| 优先级 | 实体 | 占位方案 | 正式绘制要求 |
|---|---|---|---|
| **P0（切片必绘/可读）** | 栗宝 FULL | 栗色圆角块 + 嫩芽点 | 完整剪影 + idle/run/jump/hurt 动画 + juice |
| P0 | 刺栗 / 锥冲 / 嘟浮 / 石炮 | 对应功能色基础形（红圆刺 / 红楔 / 蓝紫圆翅 / 灰方） | 完整剪影 + 动画循环 |
| P0 | 地形 ground / interactive_block | 草绿顶+橙泥矩形 / ✦ 白块 | 瓦片集 + 主题换色 |
| P0 | coin / heart / 元气果 | 金圆 / 粉心 / 紫果 纯色 | 浮动 + 拾取动画 |
| P0 | 凯旋之门 | 青色拱形矩形 | 发光门 + 通关动画 |
| **P1（切片后可补）** | 锥冲 charge_loop / 敌人 death / 道具 consume | 占位可用静态帧 | 完整帧循环 |
| P1 | fx 粒子（尘土/星光） | 小色点 | 8×8 精灵 |
| 占位即可（可长期） | 视差背景 / 远景 / 装饰 | 纯色渐变 + 矩形 | 可长期占位 |
| 矢量（非占位） | UI 图标 / 中文 / HUD | 矢量即时渲染 | 混合 UI 直接做 |

- **微信最小 demo**：P0 占位即可跑通"跑→跳→踩→顶→吃→到达"闭环；正式绘制可在 Phase 5 前补齐 P0 正式、P1 按需。

## 5. 图集规划（Atlas Plan）

- **工具**：`free-tex-packer` → 单 atlas（PNG-8 ≤64 色索引）+ Phaser JSON（ADR-004）。
- **单图集**：所有像素精灵入 **1 个 atlas**（主角/敌人/弹丸/地形/道具/终点/fx）。UI 矢量图标不入。
- **画布尺寸**：建议 `2048×2048`（最大边，留余量装 凯旋之门 64×96 与 锥冲 48×28 不切割）；实际填充远小于此。
- **体积预估**（PNG-8 ≤64 色，像素艺术高压缩）：

  | 分组 | 估算 px² |
  |---|---|
  | 栗宝 | ~19k |
  | 刺栗 | ~7k |
  | 锥冲 | ~19k |
  | 嘟浮 | ~8k |
  | 石炮 | ~5k |
  | 弹丸 | ~0.5k |
  | 地形基础集（主题 tint 不重复绘） | ~16k |
  | 道具（coin/heart/元气果） | ~7k |
  | 凯旋之门 | ~31k |
  | fx 粒子 | ~1k |
  | **合计** | **≈ 113k px²** |

  → 单图集 PNG-8 实测通常 **150–300KB**，**远低于 ≤1MB 硬限**（ADR-004）。即便洞穴/天空全量重绘（不 tint）也仅 ~150k px²，仍 <400KB。
- **装箱**：free-tex-packer 自动最优排列；输出 `atlas.png` + `atlas.json`（帧名对应实体 id，如 `en_chong_feng_charge_02`）。
- **包体**：atlas ≤1MB 计入主包（ADR-004 主包 ≤2.7MB），安全。

## 6. 可访问性 Standard 落地（Accessibility Landing）

- **高对比轮廓**：每个像素实体带 1–2px 近黑棕 `#2A1A12` 描边，任意背景可辨（accessibility §2.2/#1、美术圣经 §4.1）。
- **色盲安全调色板**：全部功能色引用美术圣经 §3.2 双编码（形状+颜色）；锥冲 红+楔形（与刺栗同红，靠楔形区分）、刺栗 红+圆刺、嘟浮 蓝紫+翅、石炮 灰+方、元气果 紫+果、爱心 粉红+心，六者形状各异、红类两敌靠轮廓区分（accessibility §2.2/#1、§9.1）。
- **减少动态（Reduce Motion）**：每实体提供静态首帧（frame 0）；开启后动画停于首帧、粒子/视差关闭（accessibility §2.2/#8、§9.3）。本清单所有动画状态均标注可静态化。
- **防光敏**：无任何全屏高频闪；受击为半透明红叠 + 角色闪烁（<3Hz），不在资产层制造闪烁（accessibility §2.2/#10、§9.3）。
- **控制热区 / 文字**：UI 为矢量，热区 ≥48×48、中文 ≥14px（accessibility §2.2/#5/#6、08-ui-hud）。
- **色盲辅助模式**：爱心/危险元素资产预置白色描边脉冲帧（开启时叠加），见 accessibility §9.1。
