# super-mali 可访问性规范（Accessibility）— Phase 3

> 文档类型：可访问性分级与特性矩阵（规范，非资产）
> 上游依据：art-bible.md v1.1 §9（可访问性）；概念文档 §5 MoSCoW、§6.5 可读性要求
> 评审强度：lean
> 用途：本文件为**可访问性分级的权威口径**。UX 规格（design-strategist 产出）须引用本文件的分级与特性矩阵；工程实现（engineering-lead）据此分级落地对应档位。美术圣经 §9 与本文件保持一致，若任一方修订须同步。

---

## 1. 分级定义与适用范围

- **三级递进**：`Basic ⊂ Standard ⊂ Comprehensive`（上级包含下级全部要求，不互斥）。
- **默认即"色盲安全"**：美术圣经已规定所有功能色必须"形状 + 颜色"双编码（§3.2 / §9.1），故即便 Basic 档也已内建色盲友好，不依赖开关。
- **安全底线不可降级**：防光敏闪烁约束（<3Hz 等）与最小触控热区（≥48×48 逻辑 px）属于强制安全下限，**Basic 档即必须满足**，任何档位不得弱化。
- **档位与工期**：MVP 目标 = **Standard**；Comprehensive 为后续冲刺档，非 MVP 阻断项。

---

## 2. 各级具体要求清单

### 2.1 Basic（基础合规）
- **色盲模式**：默认双编码设计内建（形状 + 颜色），不单独提供开关。
- **最小尺寸**：游戏内交互物体 ≥ 1 格（32px 逻辑），缩放后等效 ≥ 约 48 设备 px；UI 按钮热区 ≥ 48×48 逻辑 px。
- **减少动态**：无开关；仅遵守基础克制（粒子预算 ≤ 60、前景视差速度差 ≤ 0.3）。
- **防光敏**：全屏闪烁 < 3Hz、单次日闪 ≤ 0.2s、不连续 > 1s；受击红闪用半透明叠加而非高频白闪（安全底线）。
- **控制热区**：按钮 ≥ 48×48 逻辑 px。
- **字幕/提示**：仅游戏内既有图标/视觉提示（爱心、✦ 互动块），无系统字幕。

### 2.2 Standard（MVP 目标档 = 本作目标）
在 Basic 全部要求之上，增加：
- **色盲模式**：提供"色盲辅助模式"开关 → 危险元素与爱心加白色描边脉冲（art-bible §9.1）。
- **最小尺寸**：中文文字等效 ≥ 14px、数字/英文像素字 ≥ 10px 逻辑（清晰达标）。
- **减少动态**：提供"减少动态（Reduce Motion）"开关 → 关闭屏幕震动、粒子密度减半、通关星雨改静态（art-bible §9.3）。
- **防光敏**：同 Basic 硬底线（已满足）。
- **控制热区**：按钮 ≥ 48×48，HUD 元素按屏宽 10% 安全边距布局（art-bible §7.1）。
- **字幕/提示**：关键状态变化具备**非颜色提示**（受击 = 红闪 + 击退 + 无敌闪烁多重反馈；吃道具 = 闪光 + 缩放；顶块 = 上顶回弹 + ✦ 弹出），不依赖单一颜色通道。

### 2.3 Comprehensive（冲刺档）
在 Standard 全部要求之上，增加：
- **色盲模式**：多类型色觉缺陷预设（红色盲 / 绿色盲 / 蓝色盲滤镜，或调色板自动重映射）；白描边脉冲升级为"图标 + 描边"双强化。
- **最小尺寸**：增加"UI 缩放"选项（90%–150%）；小屏下关键 HUD 自动放大。
- **减少动态**：Reduce Motion 增强 → 关闭全部非必要粒子 / 视差 / 震动，提供"静态背景"选项。
- **防光敏**：增加"低闪烁 / 舒适模式"预设，全局进一步降低闪烁与高对比脉冲幅度（比 <3Hz 更保守）。
- **控制热区**：触控目标可放大至 ≥ 56–64px 选项；支持自定义热区缩放。
- **字幕/提示**：完整字幕系统（过场 / 提示文字）；音效文字化提示（听障友好）；所有视觉事件均具备对应文本 / 图标提示。

## 4. MVP 目标档位与 Comprehensive 增量

- **MVP 目标档位：Standard。**
  - 理由：色盲双编码已内建（Basic 即达标），Standard 仅需补"色盲辅助开关 + 减少动态开关 + 文字尺寸达标 + 热区边距"四项**低成本开关/达标项**，即可覆盖绝大多数移动端玩家，符合 lean 切片目标。
  - 阻断性：Standard 全部项均为 MVP 必须；若工期极端紧张，仅第 2/8 两个开关可降级为 Phase 4 补做，但**第 10（防光敏）与第 5（热区）为硬底线，不可降级**。

- **Comprehensive 在 Standard 之上额外增加（增量清单）：**
  1. 多类型色盲滤镜 / 调色板重映射（#3）
  2. UI 缩放选项 90%–150%（#7）
  3. Reduce Motion 增强：关闭全部非必要粒子 / 视差 / 震动（#9）
  4. 低闪烁舒适预设（#11）
  5. 触控热区可放大至 ≥ 56–64px（#12 增强）
  6. 完整字幕系统（#14）
  7. 音效文字化 / 听障友好提示（#15）

  - 以上为"体验增强 + 合规加厚"，非 MVP 阻断项；工期允许时冲刺，作为后续迭代 backlog。

- **真实缺口**：冲锋怪的**实际像素图形资产（sprite）尚未产出**，目前仅有文字剪影规范，无位图。
- **归属**：Phase 4 资产规格阶段补齐（由美术指导产出逐资产规格 + AI 生成提示词 + 实际位图）。

- **连带说明**：MVP 其余三类敌人（刺栗 / 嘟浮 / 石炮）的图形资产同样属 Phase 4，统一在资产清单（entity-inventory / asset-manifest）阶段登记，不在本文件实现。
