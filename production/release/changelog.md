## [v1.0.0] - 首个正式发布（GA）

> 这是 super-mali（**《栗宝大冒险》**）的第一个正式版本，包含 7 个完整关卡与全部核心玩法。下面按你实际能玩到的内容，分批次讲给你听。

### ✨ 新增（Added）

**🟢 批次一 · 草原 & 山川（1-1 翠野序章 / 1-2 黛峦·续章）**
- **核心玩法就位**：横版跳跃、踩扁敌人、收集金币、抵达终点的**凯旋之门**（原创终点，非旗杆）即通关。
- **四种基础敌人 + 主题专属敌**：刺栗、嘟浮、冲锋、石炮各有不同脾气——有的能踩、有的硬顶会伤你；山川关还有专属地形与机关。
- **种子精灵蜕变成长系统**（原创，替代"吃蘑菇变大"）：沿途采集种子，栗宝头顶的小嫩芽会随收集进度经历 **苗 → 藤 → 花 → 果** 四个成长阶段，并伴一圈暖黄温柔光晕。**只变外观，不影响手感、体型与分数**。
- **相对栗宝手势 + 虚拟按钮**：手机上点栗宝前方=走、点上方=跳；也可随时用屏幕底部按钮。键盘 / 触屏统一手感。
- **扔栗子战斗**：捡到栗子补给即可投掷反击远处敌人。

**🔵 批次二 · 大海（1-3 《澜屿潮汐》）**
- **潮汐与暗流**：海平面会起伏，暗流会把你轻轻推走——踩点很重要。
- **水母敌人**：可以当"踏脚石"踩上去借力，是过关的小机关。
- **五层视差海景**：天空 / 远礁 / 珊瑚 / 气泡 / 浪花，随镜头滚动出层次感。

**🟡 批次三 · 沙漠 / 家 / 街 / 办公（1-4 ~ 1-7）**
- **沙漠 1-4《灼沙绿洲》**：踏入流沙会下陷（有渐变预警），触底即回检查点；蝎子尾刺会突进、**硬顶不可踩**；仙人掌也是硬顶；还有一层**热浪蜃气**的视觉朦胧感。
- **家 1-5《归巢》**：沙发/柜子能踩能借越，桌子只能从顶上踩；宠物和玩具会蹭你一下（非致命，扣血+无敌帧）。
- **街 1-6《霓街穿行》**：横冲直撞的车辆（硬顶致命）、周期开合的井盖蒸汽（只有喷蒸汽那下才烫）。
- **办公 1-7《案牍劳形》**：文件堆是可踩平台；地上有**咖啡渍低摩擦区**，踩上去打滑难急停（纯手感挑战，不伤血）。
- 四主题各有**五层背景**与专属光影（沙幕、窗光、霓虹、荧光灯）。

**🛠 体验优化（贯穿全程）**
- **底部控制面板独占**：红框控制区内，没点到按钮的空隙不再误触发走/跳，操作更干净。
- **前期更友好**：1-1 / 1-2 移除了会发射弹丸的石炮敌人，降低开局学习曲线。
- **评级更可达**：全 7 关 `parTime`（目标时间）已放宽到普通玩家可达档，通关结算更易拿高评级。
- **暂停 / 结算 / 重试闭环**：双指轻点（或专用键 / 切后台）即暂停；抵达凯旋之门进入结算，以**矢量原创菱形星**评 1–3 级（时间 + 金币收集率各 50%），可「再玩一次」或「下一关」；失败时有温柔的「再试一次」。
- **减少动态（Reduce Motion）开关预留**：为光敏友好预留无障碍开关（默认关闭）。

### 🔧 改动（Changed）
- **更流畅、更少卡顿**：重构了游戏主循环热路径，显著降低 GC 压力与卡顿风险，整体手感更稳（尤其微信端）。
- **越界配色整改（可读性）**：石炮由灰改为**石灰白 / 深灰**双色提升辨识度；弹丸、受击闪光、连击数字由橙改为**警示红**，危险反馈更清晰、不刺眼。
- **头顶嫩芽视觉打磨**：光晕改为头顶正上方、以"稳态透明度/半径阶梯"呈现，四阶段辨识度更高（形状 + 颜色双编码，色盲安全）。
- **音频打磨（Web 端可闻）**：加入主总线限幅消除叠加削波；噪声瞬态加起音斜坡去爆音；明亮方波/锯齿音加 lowpass 滤波去刺耳；快速连采做节流防互掩。

### 🐞 修复（Fixed）
- **微信黑屏（四层兜底）**：修复了微信运行时下 Phaser 启动流程偶发不触发导致的整屏黑屏——通过钉死 `document.readyState`、补齐 `getBoundingClientRect`、补全全局 `performance.now` / `requestAnimationFrame` / `storage`、以及读取平台实例的三层兜底。**注意：该修复已在源码/构建/单测层面验证，但须在真机确认（关 G9），详见下方已知问题。**
- **手势手感**：修复跳跃态忽略水平移动、死区起步无法行走的问题。
- **微信音频静音根治**：真机首次交互后音频可正常解锁，不再整局静默（Web 端本就程序化合成可闻；微信端远程音频素材就位后同步可用）。
