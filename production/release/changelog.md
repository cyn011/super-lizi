## [v0.9.0] - 预发布（灰度条件放行）

### ✨ 新增（Added）

- **种子蜕变视觉系统**：采集关卡中的种子后，栗宝头顶的同伴嫩芽会随收集进度经历 **苗 → 藤 → 花 → 果** 四个成长阶段，并伴随一圈暖黄色的温柔光晕脉冲。仅改变外观，**不影响手感、体型与分数**（IP 安全，替代"吃蘑菇变大"）。
- **种子跨关成长记录**：本局采集的种子数会被记录并跨关卡保存，重进游戏后保留（老存档自动兼容，不丢档）。
- **新关卡 1-2 + 进度链**：通关 1-1 的凯旋之门后解锁 1-2，结算页出现「下一关」；1-2 为末关时自动隐藏「下一关」、仅保留「再玩一次」。
- **暂停 / 结算 / 重试闭环**：
  - 双指轻点（或专用键 / 切后台）即可暂停，弹出「继续」「重玩」。
  - 抵达凯旋之门进入结算页，以**矢量原创菱形星**评定 1–3 评级（时间 + 金币收集率各占 50%），可「再玩一次」或「下一关」。
  - 失败（命耗尽）时温柔提示「再试一次」。
- **相对栗宝手势增强**：微信端现在支持**跳跃中左右拖动空中换向**、以及从栗宝附近死区起步即可行走，操作更跟手。
- **减少动态（Reduce Motion）开关**：为光敏友好预留的无障碍开关（默认关闭），开启后跳过蜕变光晕脉冲动画。

### 🔧 改动（Changed）

- **更流畅、更少卡顿（性能优化）**：重构了游戏主循环的热路径，消除了每帧大量临时对象分配（稳态分配归零），并引入弹丸对象池。在微信端（JSCore）可显著降低 GC 压力与卡顿风险，整体手感更稳。
- **越界配色整改（可读性）**：石炮由灰改为**石灰白 / 深灰**双色以提升辨识度；弹丸、受击闪光、连击数字由橙改为**警示红**，危险反馈更清晰、不刺眼。
- **头顶嫩芽视觉打磨**：移除占位的"双芽点"，光晕中心改为头顶正上方并以"稳态透明度/半径阶梯"呈现，四阶段辨识度更高（形状 + 颜色双编码，色盲安全）。
- **音频打磨（Web 端可闻）**：
  - 加入主总线限幅（MasterBus Compressor），消除同帧多音叠加导致的轻微削波失真。
  - 噪声瞬态加入起音斜坡，去除"啵/啪"爆音。
  - 明亮的方波/锯齿音（踩敌、受伤等）加入 lowpass 滤波，去刺耳。
  - 快速连续采集时做节流，避免高频 spam 互掩。

### 🐞 修复（Fixed）

- **微信黑屏（四层兜底）**：修复了微信运行时下 Phaser 启动流程永不触发导致的整屏黑屏——通过钉死 `document.readyState`、补齐 `getBoundingClientRect`、补全 `performance.now`/`requestAnimationFrame`/`storage` 全局、以及 GameScene 读取平台实例的三层兜底。**注意：该修复已在源码/构建/单测层面验证，但尚未在模拟器/真机实跑，须按下方已知问题在真机确认（关 G9）。**
- **手势手感**：修复跳跃态忽略水平移动、死区起步无法行走的问题（见"新增·手势增强"）。
