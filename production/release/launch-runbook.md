## 1. Web 端部署步骤（🟢 GO-READY）

> Web 为确定性最强的通道（浏览器渲染确定、headless 双端等价已验证）。出包后即可部署，建议补一次 Web 真机冒烟留痕（非硬阻断）。

### 1.1 出包
```bash
npm run build:web        # → dist/  (index.html + assets/index-*.js + game.js + game.json + mali-app-icon-144.png)
```
- [ ] 出包成功，无报错。
- [ ] 体积复测：`dist/` 合计 ≈1.65 MB ≤ 2.7MB（§3.2）✅ 余量 ~39%。
- [ ] 文件齐：`index.html` + `assets/index-*.js` + `game.js` + `game.json` 存在。

### 1.2 静态托管 / CDN
- `vite.config.ts` 已设 `base: './'` → 产物可直接托管到任意静态服务（对象存储 + CDN / GitHub Pages / Vercel / Netlify 等）。
- [ ] 上传 `dist/` 全部内容到目标根路径（保持相对路径）。
- [ ] 配置 HTTPS（微信分享/音频解锁等需安全上下文）。

### 1.3 Staging → Prod 冒烟
- [ ] staging 域名打开：首屏无红错、栗宝可见、标题屏「栗宝大冒险」+ 开始按钮正常。
- [ ] 进 1-1：跑通 出生 → 踩敌/吃币/受伤重生 → 凯旋之门 → 结算（菱形星评级）→ 下一关解锁。
- [ ] 留痕：console 无红错日志截图 ≥1。
- [ ] 切 prod 域名 / 刷新 CDN 缓存。
- [ ] prod 冒烟（同上）通过 → **标记 Web 上线完成（v1.0.0）**。

### 1.4 Web 真机冒烟（建议，非硬阻断）
- [ ] 手机浏览器打开 prod 地址：触控手势（点前方走/点上方跳）+ 双指暂停 正常。
- [ ] 留痕截图 ≥2（首屏 + 通关结算）。

## 4. 回滚方案（Rollback）

> 原则：所有回滚命令须经**主理人审批**后由工程侧执行；本 Runbook 仅提供可执行步骤，不代为执行（且全程未 commit）。

### 4.1 代码级回滚（git）
```bash
# 方案 A（推荐，保留历史）：revert 发布提交
git revert <发布commit>            # 生成反向提交，安全可审计

# 方案 B（紧急）：检出上一稳定版文件树（须重新 build）
git checkout <上一稳定tag> -- .

# 版本锚定（发布时由主理人审批后打 tag）
git tag -a v1.0.0 -m "super-mali v1.0.0 正式发布" <发布commit>
```

### 4.2 构建产物回退（无需重 build 源码）
- 发布前**归档上一稳定版** `dist/`、`dist-wechat/`（按版本目录备份：`dist-v1.0.0-rc/`、`dist-wechat-v1.0.0-rc/`）。
- 回滚时：恢复归档产物 → 重新部署（Web）/ 重新上传体验版（微信）。

### 4.3 微信端回退
- **体验版**：直接重新上传上一稳定版 `dist-wechat/` 覆盖。
- **正式版**：微信无一键回滚 → 须**重新提审** 或利用**分阶段发布**将流量切回上一稳定版（故首次发布必走分阶段）。
- 黑屏等致命故障：立即将分阶段发布流量降为 0 + 重新上传体验版验证修复 → 再提审。

### 4.4 应急决策速查
| 故障 | 判定 | 动作 |
|---|---|---|
| Web 首屏崩 / 真机红错 | blocker | 回退 CDN 到上一稳定产物（4.2） |
| 微信黑屏（未真机验证即上线） | 致命 | 分阶段流量降 0 + 重新上传验证（4.3）；复盘 G9 放行流程 |
| 音频异常（爆音/无声音） | 非致命 | 记 known issue，下个热修；Web 可热更，微信走体验版验证后提审 |

## 5. 热修路径（Hotfix）

> 热修走**简化流程**但**保留完整审计与回滚预案**（§4）。热修不豁免 IP / 包体红线。

### 5.1 触发条件
- 线上 P0/P1 缺陷（崩溃、卡死、致命手感 bug、IP 合规漏网）。
- **不用于**：新功能、内容扩展、非紧急调参（走正常迭代）。

### 5.2 热修步骤
1. [ ] 从当前发布 tag 拉 `hotfix/v1.0.0-x` 分支，最小改动修复。
2. [ ] 本地复跑：`npx tsc --noEmit`（0 错）+ `npm test`（全绿，当前 549）+ 对应真机/模拟器冒烟。
3. [ ] 出包（§1.1 / §2.1），复测体积（≤2.7MB）与四件齐全。
4. [ ] 主理人审批 → bump 补丁版本（`v1.0.0 → v1.0.1`）+ git tag + 出包上线。
5. [ ] Web：重新部署归档；微信：**体验版验证 → 提审/分阶段发布**（微信热修同样需走审核，无免审热更）。
6. [ ] 留痕：changelog 增补 hotfix 条目 + 回滚预案（§4）备查。

> ⚠️ **微信端无免审热更**：即使是热修，正式生效仍需走体验版验证 + 提审/分阶段发布。Web 端可直接重新部署。
