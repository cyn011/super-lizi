**判定**：旧档含 `stars` 加载不崩且迁移为 `ranks`、多关解锁态正确累积、损坏档回退 default → PASS；任一崩溃/丢档/迁移失败 → FAIL（回 S05-3 `SaveManager.migrate`）。

## 8. §8 S05-1 节拍平台手测（BeatDrivenSystem · 双端）

> 背景：S05-1 将 `BeatClock` 接真实 `game-scene` + `BeatDrivenSystem` 节拍平台。`BeatDef.tracks` 用 `pattern` 周期串（`S`=solid 实相位可踩、`G`=ghost 虚相位可穿）按 `beatIndex % len` 取相位；单拍时长由关卡 bpm 决定。
> 实测语义（见 `1-1.json` / `1-2.json` 谱面）：
> - **1-1 `bp_pulse_a`**：`tiles:[{tx:17,ty:4},{tx:18,ty:4}]`，`pattern:"SSSSSSSSGGGGGGGG"`（8 实 + 8 虚 = 16 拍），单拍 **500ms** → **500ms 实相位 / 500ms 虚相位**。
> - **1-2 `bp_1_2`**：`tiles:[{tx:19,ty:5},{tx:20,ty:5},{tx:21,ty:5}]`，`pattern:"SSSGGG"`（3 实 + 3 虚 = 6 拍），单拍 **187.5ms** → **187.5ms 实相位 / 187.5ms 虚相位**。

**步骤（Web + 微信模拟器/真机，双端各跑一遍，覆盖 1-1 与 1-2）**
- [ ] 1-1 抵达 `bp_pulse_a`（tx17–18, ty4）区段：观察平台**实相位（实心、可站立）**与**虚相位（半透明、可穿过）**按 500ms/500ms 周期切换。
- [ ] 1-2 抵达 `bp_1_2`（tx19–21, ty5）区段：观察 3 实 + 3 虚周期，**187.5ms 实 / 187.5ms 虚**（节奏明显更快）。
- [ ] **可踩实相位**：玩家站上实相位平台不掉落、可借力跳起；站在虚相位上**无碰撞支撑、直接穿过下落**（应为安全下落，非死亡陷阱）。
- [ ] **穿虚相位**：玩家在虚相位期间穿过平台、落到下层地形，无异常卡死/瞬移。
- [ ] 连续多次在相位边界处尝试站立/穿越，判定稳定、无闪烁误判、无穿模卡入 tile。

**判定**：双端（Web + 微信）`bp_pulse_a`(500/500) 与 `bp_1_2`(187.5/187.5) 实/虚切换符合 pattern 语义、可踩实/穿虚/下落安全 → PASS；任一端相位错乱/穿模/误判死亡 → FAIL（回 S05-1 `BeatDrivenSystem` / `beat-driven-system.test.ts`）。
