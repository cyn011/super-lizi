### §4 ⑧-a 【必须用户真机/模拟器】S05-3 旧档迁移手测（G5：`stars`→`ranks` 一致性）

**步骤（Web + 微信模拟器，双端各跑一遍）**
- [ ] **预制旧档**：在 `localStorage` / `wx` 存储中写入含 `stars` 键的旧版存档（如 `{"stars":{"1-1":3},"unlockedLevels":["1-1"],"bestTimes":{"1-1":12345}}`，无 `version` 或 `version<1`）。
- [ ] 启动游戏 → 加载该旧档：**不崩、不丢档**，且迁移后读取为 `ranks`（等价 `{"1-1":3}`），`stars` 键不再使用。
- [ ] 通关 1-1 → `recordClear` 落盘：评级写入 `ranks["1-1"]`（取历史最大）、解锁 1-2 进 `unlockedLevels`；旧档玩家进度无缝延续。
- [ ] 预制**损坏档**（非法 JSON 串）→ 启动加载回退 default（首关 1-1 解锁、`ranks` 空），不崩。
- [ ] **多关累积**：依次通关 1-1、1-2（见 §9），`unlockedLevels` 累积为 `["1-1","1-2"]`，`ranks`/`bestTimes`/`bestCoins` 各关独立记录最优。

**判定**：旧档含 `stars` 加载不崩且迁移为 `ranks`、多关解锁态正确累积、损坏档回退 default → PASS；任一崩溃/丢档/迁移失败 → FAIL（回 S05-3 `SaveManager.migrate`）。
