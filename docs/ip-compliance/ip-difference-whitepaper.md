## 1. 摘要与结论

> **一句话结论**：本游戏（《栗宝大冒险》）的全部"具体表达"——包括原创角色"栗宝"及其造型、所有符号与图标、全部敌人、道具、关卡机制、像素美术、代码与音乐——均为项目团队独立创作，与任天堂《超级马里奥》（Super Mario）系列**不存在任何复制、移植或派生关系，不构成抄袭**。横版跳跃（side-scrolling platformer）为游戏行业共有品类，其玩法类型不受任何单一厂商版权垄断；本作在品类之上叠加了两个马里奥系列所没有的**原创差异内核**（种子精灵蜕变成长系统、音乐节拍化关卡），建立了独立可辨识的原创 IP 身份。

**合规要点速览**
- 项目立项即设有明确 **IP 红线**（禁用任天堂符号：水管工 / 蘑菇 / ★ 星星 / 旗杆 / 龟壳等），并以文档（`art-bible` §1、MEMORY.md）与实现（标题屏菱形星点、凯旋之门替代旗杆）双重落地。
- 角色、敌人、道具、终点、收集物、机制**全部为原创命名与原创造型**，无任天堂资产引用。
- 所有素材（像素美术、代码、程序化音频）均为团队自研，**零外部抄袭素材**。
- 像素风为品类共有表达自由，非任天堂专利；本作锁色板与角色造型均自研（art-bible §3）。

## 3. 核心差异内核

本作在"横版跳跃"共有品类之上，叠入了两个马里奥系列所不具备的原创系统。二者在设计中**正交、零共享状态**（GDD 12 §3.7 与 beat-design.md §1.1 明确决议），并行存在、互不耦合，共同构成项目的"差异内核"（concept §7 核心定位）。

### 3.1 种子精灵蜕变成长系统（Seed Metamorphosis）— GDD 12

- **它是什么**：玩家在关卡内采集"种子"实体 → `growthPct` 累积 → 经阈值推导 `stage`（苗 `sprout` → 藤 `vine` → 花 `bloom` → 果 `fruit`）→ 驱动栗宝头顶 topper 切换（嫩芽抽枝 → 开花 → 结果）+ 暖黄光晕 tween + `sfx:seed_metamorph`（GDD 12 §3.1、§3.8，与 art `computeGrowth` 对接）。
- **与马里奥蘑菇的本质区别**：
  - 马里奥吃蘑菇 = **身体尺寸变大**（改碰撞盒 / 受击状态）；
  - 本作采种子 = **头顶"同伴式蜕变"**，**仅改视觉**（topper / 光晕），**不改尺寸、不改 `sizeScale`、不改 `form`、不改任何数值能力**（GDD 12 §3.5、验收标准）。这是有意为之的 IP 安全设计——既保留"拾取即成长的可触摸反馈"爽感，又**规避蘑菇 / 变大轮廓**这一任天堂强符号。
- **原创性佐证**：
  - 4 阶段权威枚举（苗/藤/花/果）由 art-bible §1.3 `computeGrowth` 定义，GDD 12 裁定为唯一真理源（附录 A）；
  - 数据模型（`SeedMeta` / `SeedRuntimeState`）、事件契约（`ON_SEED_COLLECTED` / `ON_SEED_GROWTH` / `ON_SEED_METAMORPHOSIS`）、`seed-config.json` 全部自研；
  - 与 GDD 06（元气果 `form` 能力态）正交，术语 `seed`（采集物/成长驱动）与 `form`（能力态）严格区分，杜绝命名冲突（GDD 12 §3.4）。
- **辨识度价值**：把"成长"变成头顶嫩芽抽枝开花的**可视冒险动词**，呼应"种子唤醒大地"世界观，是玩家一眼区别于马里奥的核心记忆点。

### 3.2 音乐节拍化关卡（Beat-Level）— GDD 10 + beat-design.md（S05-1 已落地）

- **它是什么**：`BeatClock`（纯逻辑、确定性，已实现于 `src/core/beat/beat-clock.ts`）产出整拍序号 → `BeatDrivenSystem`（S05-1 提交 `1e4849c`）按谱面 `tracks` 在跨拍瞬间切换"节拍平台"的 `solid/ghost` 相位 → 物理层 `isSolidTile` 实时反映 → 平台随乐律明灭、可踩/可穿。把 **Sensation（感官）美学做成机制**（concept §7、beat-design.md §1.2 MDA）。
- **与马里奥的本质区别**：马里奥系列**没有任何"关卡元素随背景音乐节拍变化"的机制**。本机制为平台跳跃品类中的原创玩法维度（"读拍—起跳—落点"新决策层）。
- **原创性与 IP 安全设计**：
  - 谱面 schema（`BeatTrackEntry` 的 `S/G/T` 相位字符、`BeatPlatformDef` 的 `tiles` id 引用）为自研设计契约（beat-design.md §2）；
  - 机制红线：节拍平台**不产分、不产币、不产种子**（遵循 GDD 12 §R2 防刷分），为**可选/局部**节奏挑战，不阻断通关路径（1-1 地面连续，beat 段仅复用浮空块 `bp_pulse_a`，beat-design.md §5）——**无主导策略、无经济失衡、无认知过载、无支柱漂移**（设计理论四禁自查通过，§1.3）；
  - IP 命名/视觉用"种子 / 藤蔓 / 明灭"，**禁用星/蘑菇/旗杆命名**（beat-design.md §1.2、§8）。
- **辨识度价值**：将"音乐律动"从氛围升级为可玩机制，是本作区别于一切传统横版跳跃（含马里奥）的**机制级差异点**，且已通过 headless 确定性验证（beatEvents 断言、`finalHash` 含相位）。

> 注：节拍化关卡 MVP 阶段为"预留接口 + 局部点亮"（GDD 10 分层 Must/ Could），但时钟与机制骨架已真实落地（S05-1），属本作**已实现的原创差异内核**，非设想。

## 4. 法律 / 合规边界说明

### 4.1 版权保护"具体表达"，不保护"玩法类型"

- 著作权（版权）只保护作品的**具体表达（expression）**，不保护**思想、玩法类型、功能、通用游戏规则（ideas / game mechanics / genres）**。横版卷轴跳跃（side-scrolling platformer）自 1980 年代即属行业共有品类，任何厂商都**无权垄断**"左右移动 + 跳跃 + 踩敌 + 收集 + 抵达终点"这一玩法类型。
- 任天堂对马里奥的版权仅及于其**特定角色造型、特定美术资产、特定音乐、特定文本**等具体表达；本作未复制其中任何一项（见 §2 对比表与 §3 差异内核）。
- 因此，即便两作同属"横版跳跃"，只要**具体表达各自独立创作**，即不构成版权侵权。本作正是后者。

### 4.2 我们的具体素材零复制

| 素材类别 | 来源 | 是否复制任天堂 |
|---|---|---|
| 角色造型（栗宝） | 美术圣经 §4.2 定义 + 自绘像素（title-scene.ts `drawMali`） | 否，独立原创 |
| 敌人（8 类） | GDD 04/13–16 + `src/core/enemy/*` 自研状态机 | 否，独立原创 |
| 道具 / 收集物 | art-bible §6.1（元气果/壳珠/金币/种子）+ 菱形星点 | 否，独立原创（禁蘑菇/★） |
| 关卡 / 终点 / 管道 | `triumph_gate` 实体 + 藤蔓筒/发光柱 + "✦"块 | 否，独立原创（禁旗杆/绿管/?） |
| 像素美术 | 自研锁色板（≤64 色）+ 32px 网格，资产自绘 | 否，独立原创 |

> 项目备忘（MEMORY.md）明确立项定位："原创'马里奥式'横版跳跃微信小游戏（**非**任天堂克隆；IP 红线：禁用水管工/蘑菇/星星/旗杆/龟壳等符号，角色与美术全原创）"。代码层亦实测 `src/core` **零 window/document/wx/phaser 实依赖**（仅注释提及），无外部资产引用。

### 4.3 平台审核（微信小游戏 / 应用商店）原创性视角

- **微信小游戏 / 各应用商店**审核关注：① 是否侵犯第三方知识产权（含版权、商标）；② 是否冒用知名 IP；③ 素材是否为原创或可商用授权。
- 本作应对优势：
  - **全原创素材**：角色、美术、代码、程序化音频均自研，无第三方素材风险；
  - **无知名 IP 冒用**：未使用任天堂或任何第三方的角色名、商标、符号；游戏名《栗宝大冒险》与"马里奥/Mario"无混淆性近似；
  - **IP 红线已工程化落地**：标题屏用词为"像素风横版跳跃冒险"（副标题，title-scene.ts），属品类客观描述，无"马里奥"字样；★ 已替换为原创菱形星（`star→rank` 重命名，EL-STAR-FIX）；
  - **世界观独立**："种子精灵唤醒大地"暖色奇幻叙事，与任何现存 IP 不重叠。
- 建议上线物料（图标、截图、介绍文案）继续沿用既有原创设定（`mali-app-icon-144.png` 栗宝全身 + 天蓝徽章底；审核截图 v3 ×5 主题各异），并避免在任何文案中出现"马里奥/超级玛丽/Mario"等对比或近似表述。

## 5. 合规备查清单（上线前逐项确认）

> 用途：每次提审 / 上线前逐项勾选，确保无任天堂符号残留、素材全原创。责任：design-strategist 起草，主理人 / 美术指导 / 工程主程复核。

### A. 角色与符号（无任天堂符号残留）
- [ ] 主角栗宝无红帽 / 背带裤 / 胡子 / 蘑菇头 / 龟壳（art-bible §4.2 绝对禁忌）；头顶为嫩芽非帽子。

- [ ] 全游戏**无** 旗杆；终点均为 `triumph_gate`（凯旋之门）。
- [ ] 全游戏**无** 绿色直管（Warp Pipe）；管道替代物为藤蔓筒 / 发光柱。
- [ ] 全游戏**无** "?" 砖块；可顶块为 "✦" 互动块。
- [ ] 文案 / 界面**无** "马里奥 / 超级玛丽 / Mario / Nintendo / 任天堂" 等字样或近似表述。

### B. 敌种与机制全原创
- [ ] 敌人仅含自研 8 类（ci_li / chong_feng / du_fu / shi_pao / gu_bao / bouncy_vine / cyclone / du_fu_silhouette），**无** 板栗仔 / 龟壳 / 乌龟。
