# super-mali · 游戏概念文档（Phase 1 概念孵化）

> 版本：v0.1（Phase 1 概念）
> 作者：文策渊（design-strategist）
> 引擎：Phaser 3（TypeScript + Vite）
> 目标平台：Web + 微信小游戏双端
> 评审强度：lean（仅在关键阶段过质量门）
> 说明：本项目为"马里奥式"横版卷轴跳跃平台游戏，借鉴核心机制（跑/跳/踩怪/顶砖/吃道具/到达终点），但角色、美术、关卡、音乐、世界观全部原创，规避任天堂 IP 风险。这是一个"马里奥式"平台跳跃游戏，不是马里奥克隆。

---

## 1. 游戏支柱（Design Pillars · 动词优先）

以"玩家核心体验动词"为先导，三条支柱互相支撑，后续所有系统取舍以此为准绳。

- **P1 · 跳（精准掌控）**：让玩家每一次起跳、二段跳、下落踩踏都获得精准、可控、有节奏感的"身体掌控"体验——手感是第一优先级，宁可少内容也要把跳跃调到位。
- **P2 · 闯（横版推进与探索）**：让玩家在不断向右展开的横版关卡中，边跑边发现隐藏路径、秘密砖与节奏变化，把"推进"变成带惊喜的冒险动词。
- **P3 · 蜕变（道具驱动成长）**：让玩家通过吃下原创道具获得形态/能力变化，把"成长"变成可触摸、可即时感知的冒险动词，而非数值面板。

> 支柱检验标准：任何被提议的功能，若不能同时服务于"跳 / 闯 / 蜕变"三者之一，且不属于 Must 基础支撑，则应降优先级或砍掉。

## 2. MDA 框架分析

### 2.1 Mechanics（核心机制清单）

| 编号 | 机制 | 说明 |
|------|------|------|
| M1 | 跑动 | 左右移动，含加速度/减速度/惯性（非瞬间启停） |
| M2 | 跳跃 | 单跳 + 二段跳；含土狼时间（coyote time）、跳跃缓冲（jump buffer）、可变跳跃高度（松键减速） |
| M3 | 踩踏 | 从上方下落接触敌人头部触发消灭（stomp），并给一次小反弹 |
| M4 | 顶砖 | 从下方顶撞可顶碎/顶出道具的砖块 |
| M5 | 道具拾取与形态切换 | 吃下原创道具进入对应形态，形态决定能力（见 P3） |
| M6 | 生命与受伤状态机 | 受伤→缩小→死亡；含无敌帧（i-frames）、短暂硬直 |
| M7 | 终点判定 | 到达终点旗/终点门即关卡完成 |
| M8 | 重力/碰撞/平台物理 | 平台、单向平台、移动平台、坠落坑 |

### 2.2 Dynamics（机制组合产生的玩法动态）

- **跑 + 跳 + 踩踏（M1+M2+M3）** → 形成"冲刺—跳跃—踩踏"的连续节奏流，构成核心爽点。
- **二段跳 + 平台布局（M2+M8）** → 玩家可规划空中路线，产生探索分支与"我能不能跳过去"的策略判断。
- **顶砖 + 道具（M4+M5）** → 资源分配博弈：何时吃、是否留作储备、是否冒险顶高处的砖。
- **受伤缩小（M6）+ 高风险区** → 风险回报权衡：高价值道具区天然等于高风险区。
- **隐藏路径（M1+M2+探索）** → 重复可玩性：同一关有"速通线"与"收集线"两条体验。

### 2.3 Aesthetics（追求的 8 种美学乐趣）

| 美学 | 定位 | 说明 |
|------|------|------|
| **Challenge（挑战）** | ★ 主 | 精准操作、通关、无伤/速通追求 |
| **Discovery（探索）** | ★ 主 | 隐藏路径、秘密砖、彩蛋 |
| Sensation（感官） | ○ 次 | 跳跃手感爽快、音乐节拍、粒子反馈 |
| Fantasy（幻想） | ○ 次 | 原创"种子唤醒大地"的奇幻世界观 |
| Expression（表达） | ○ 弱 | 可选形态/皮肤（仅装饰，不影响数值） |
| Narrative（叙事） | △ 极弱 | 本期不做剧情章节，世界观靠环境暗示 |
| Fellowship（社交） | ✕ 无 | 单机为主，不做联机 |
| Submission（消遣） | ✕ 无 | 非放置/挂机体验 |

**主打：Challenge + Discovery；辅助：Sensation + Fantasy。**

## 3. 玩家心理学

### 3.1 自我决定论（SDT · 三大需求）

- **自主（Autonomy）**：关卡内多条路径与隐藏路线、道具使用时机的自主选择，让玩家"我的路线我做主"。
- **胜任（Competence）**：精准手感 + 清晰难度梯度 + 即时正反馈（踩怪音效、粒子、分数飘字、连击），让玩家持续感到"我能行"。
- **关联（Relatedness）**：单机下偏弱；可借微信轻量"成绩炫耀/好友排行"做弱关联（见 MoSCoW · Could），但本期不依赖。

### 3.2 Bartle 玩家类型

- **主打：Achiever（成就型）**——追求通关、收集、分数、无伤、隐藏内容解锁。难度梯度与收集要素为其设计重心。
- **兼带：Explorer（探索型）**——隐藏路径、秘密砖、彩蛋满足探索欲。
- **非重点：Killer / Socializer**——不做 PvP、不做强社交。

### 3.3 心流平衡（Flow）

- **关卡内难度波浪**：单关采用"易—难—易—难峰—终点缓降"的波浪曲线，避免持续高压或持续平淡。
- **技能匹配**：二段跳、道具形态、移动平台等机制**循序渐进解锁**，前 1/3 关做教学化低负担引入，避免早期认知过载。
- **公平失败惩罚**：检查点/重生点间距短、死亡成本低，保证"有挑战但公平"，维持挑战区与技能区的重叠（心流通道）。

## 4. 核心循环（Core Loop）

### 4.1 单关内循环（行动 → 反馈 → 奖励 → 再来）

```
行动  玩家跑动/跳跃/踩怪/顶砖，遭遇平台、陷阱、敌人
  ↓
反馈  踩怪：音效+粒子+分数飘字+小反弹；受伤：红光+无敌帧；顶砖：碎裂/弹出道具
  ↓
奖励  获得金币/分数、道具形态、隐藏砖中的秘密、到达子目标
  ↓
再来  继续向右推进，下一个挑战点（更复杂平台/更强敌人/节奏变化）出现
```

### 4.2 元循环（关卡推进 → 成长）

```
通关一关 → 解锁下一关 / 新道具形态 / 新机制（如移动平台）
  ↓
能力成长（形态库扩充、操作熟练度提升）
  ↓
挑战更高难度世界/关卡
  ↓
到达世界终点（阶段目标）→ 进入下一世界或 Boss（Could）
```

## 5. 范围分层（MoSCoW）

> lean 模式目标：快速产出可玩切片（playable slice），MVP 边界必须清晰、可一周内出闭环。

### Must（MVP 必做 · 可玩切片）
- 核心跳跃手感：跑动惯性、单跳 + 二段跳、踩踏、顶砖、重力/碰撞物理（含 coyote time / jump buffer）
- 3~5 种原创敌人（建议：地面慢怪、地面冲锋怪、飞行怪、钻地怪 ×4）
- 1 个可玩关卡（含起点教学段 / 中段挑战 / 终点旗）
- 基础 HUD：生命、金币/分数、关卡进度条、计时
- 受伤/缩小/死亡/重生 状态机 + 检查点
- 原创主角 + 至少 1 个原创道具形态

### Could（后续迭代）
- Boss 战（世界终点守护者）
- 道具树 / 多形态成长系统（P3 深化）
- 内部关卡编辑器（加速量产）
- 动态音乐（关卡随节拍变化，见差异化卖点）
- 微信轻量成绩分享/好友排行（弱关联）

### Won't（本期不做）
- 联网对战（PvP）
- UGC 分享 / 玩家社区
- 剧情章节（Narrative 极弱，世界观走环境暗示）
- 物理破坏沙盒

## 6. 视觉锚点（关键交付物 · 供美术总监出美术圣经）

> 本节为美术圣经（art-bible）的输入依据，须足够具体、可落地、可验收。

### 6.1 美术风格取向（明确推荐）
- **推荐：现代清晰像素风（Modern Crisp Pixel Art）为主，矢量扁平 UI 为辅。**
- 理由：① 像素资产体积小，天然契合微信小游戏包体限制；② 小屏可读性强、量产成本低；③ "清晰像素"（整数缩放、无模糊）兼顾复古质感与现代观感。
- **不推荐手绘卡渲**：成本与包体过高，与 lean 快速切片目标冲突。
- 混合建议：游戏世界用像素，HUD/菜单/图标用矢量扁平（保证文字清晰、跨分辨率稳定）。

### 6.2 色调与情绪
- **主色板方向**：
  - 基底暖色：暖橙黄（阳光、活力、友好基调）
  - 自然辅色：青绿 / 墨绿（草地、丛林、自然环境）
  - 警示点缀：暖红 / 玫红（敌人、危险、道具警示）
- **明暗**：中等明度、高对比（保证小屏与户外/室内高光环境可读）；避免大面积暗场景。
- **情绪**：温暖、轻快、冒险、童趣但不幼稚；危险区用冷蓝/紫做反差提示。

### 6.3 角色剪影方向
- **主角（原创"种子精灵"）**：
  - 体型：矮胖圆润，"果核/豆形"轮廓，约 1.2~1.5 头身比（矮墩墩、无脖颈）。
  - 辨识度来源（落到形状）：**顶部一片小嫩芽/叶形头饰** + 圆胖无脖颈的豆形身体 + 大眼睛（表情靠眼睛+腮红）。
  - 配色：暖橙黄主体 + 深棕/近黑描边。
  - 禁忌：不得出现帽檐、背带裤、大胡子、水管工轮廓等任何易与任天堂角色混淆的造型。
- **敌人剪影（形状编码，便于小屏辨识）**：
  - 地面慢怪：**带刺圆球 / 仙人球状**（圆 + 尖刺，提示"可踩但边缘危险"）。
  - 飞行怪：**有翅灯笼形**（上圆下飘、两侧小翅，提示"空中、可踩顶"）。
  - 冲锋怪：**长条楔形**（前尖后宽，体现方向感与冲撞威胁，提示"不可正面踩"）。

### 6.4 参考游戏 / 作品（借什么，不借什么）
1. **Celeste** — 借：精准跳跃手感、像素角色小屏可读性、冷暖对比。
2. **Shovel Knight** — 借：复古像素的现代打磨感、关卡节奏、敌人辨识度。
3. **Super Mario Bros.（仅参考结构，规避全部美术/角色）** — 借：横版卷轴推进节奏、挑战峰布局；**不借任何美术、角色、命名**。
4. **Hollow Knight** — 借：氛围质感启发（改用明亮版，不借暗调与角色）。
5. **Stardew Valley / Terraria 像素** — 借：暖色自然色调、可读像素环境。

### 6.5 可读性要求（小屏硬指标）
- 在约 375px 宽手机屏、角色等效 **24px** 尺寸下，主角、敌人、陷阱、道具、终点必须**一眼可辨**。
- **双重编码**：敌人用"形状 + 颜色"双重提示（圆=可踩；尖刺=不可踩；红/暖=危险；绿=可交互道具）。
- **陷阱醒目**：尖刺/坑必须与地面有明显色差 + 描边，杜绝"看不清致死"。
- **道具动效**：道具用发光/脉冲动画，与静态砖块明确区分。
- **主角描边**：主角始终带 1~2px 深色描边，在任何背景上不丢失。

## 7. 差异化卖点

**核心定位（一句话）**：
> 原创 IP 的马里奥式手感平台跳跃——以"种子精灵蜕变"成长系统替代"蘑菇变大"，并以"音乐节拍化关卡"为差异内核，在规避任天堂 IP 的同时保留核心爽感。

- **机制差异**：用"道具形态蜕变"（多种原创形态，各自独特能力）替代单一变大/无敌，成长更可读、更有策略。
- **题材差异**：原创"种子精灵唤醒沉睡大地"暖色奇幻世界观，自然主题关卡（草原/石窟/云端），与水管工题材彻底区隔。
- **系统差异（潜力点）**：关卡元素随背景音乐节拍变化（节拍平台/节拍陷阱），把"Sensation"美学做成机制而非仅氛围（MVP 可仅预留接口，Could 阶段深化）。

## 8. 已知风险与缓解

| 风险 | 缓解方向 |
|------|----------|
| **IP 风险** | 玩法可借鉴，但角色/美术/音乐/世界观/命名全部原创；美术圣经建立"无任天堂资产、无混淆性命名"红线，评审时专项核查。 |
| **手感调校风险** | MVP 先做独立"手感沙盒"调试场景，用数据量化（跳跃高度/滞空/土狼时间/跳跃缓冲/二段跳窗口），手感达标再铺内容。 |
| **双端适配风险** | 抽象输入层：键盘（Web）与触屏虚拟摇杆（微信）统一映射到同一输入事件（左/右/跳/动作），逻辑层不感知平台。 |
| **微信包体限制** | 主包 4MB、整包 8MB 上限；像素资产体积小天然友好，音乐走短循环/流式，美术走打包图集（atlas），避免高清位图。 |
| **难度曲线风险（lean 切片易忽略）** | MVP 关卡套用"波浪难度"模板（每约 200px 一个挑战峰），保证心流通道，避免早期过载或全程平淡。 |
| **范围蔓延风险** | 严守 MoSCoW：Boss/道具树/编辑器/社交一律归入 Could/Won't，MVP 只交付"手感 + 1 关 + 基础系统"。 |

### 附录 · 下一步建议（供主理人决策）
1. 主理人确认三条支柱与核心定位是否准确（尤其"音乐节拍化关卡"是否纳入 MVP 预留接口）。
2. 确认 MVP 敌人数量取 3 还是 5（影响切片工作量与手感调试时间）。
3. 美术方向若认可"现代清晰像素"，即可据此启动美术圣经 v0.1。
