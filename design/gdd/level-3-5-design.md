## 1. 关名与叙事节拍

**关名：《凌霄绝息》**（主计划 §9 拍板项 ④ 已定；备选《危穹独渡》《薄气高天》）

> **命名对称**：与 **3-1《浮空初息》** 成对——**初息**（第一口空气）↔ **绝息**（最稀薄的一口）。章内首尾呼应，同 Ch2「终焉」的命名手法。「凌霄」直指本关的构图主体：**三层浮岩塔**。

### 1.1 在 ascend 弧线上的位置

| 弧线段 | 关 | 一句话 |
|---|---|---|
| 发现 | 3-1 | 「我能慢下来了」 |
| 尺度 | 3-2 | 「这地方比我想的大得多」 |
| 上行 | 3-3 | 「星界在呼吸；踩着它的节拍，我第一次真的往上了一层」 |
| 阻力 | 3-4 | 「星界不欢迎我。慢下来，就成了靶子」 |
| **极限** | **3-5《凌霄绝息》** | **「我不再只是飘——我在攀。而头顶那不是天，是一层壳」** |
| 突破 | 3-6 | （批 C） |

**叙事节拍（三段，承接 3-4 段 3「学会收翅」）**

- **段 1 · 一口气不够了**：躲过陨雨之后，栗宝继续往上。风变薄了，翅膀撑开的那一下**没有以前那么托得住**——一次滑翔只够到半路。它第一次发现：**光靠飘，够不到上面那块岩**。
- **段 2 · 借力**：半空里飘着一只光精灵（`du_fu`）。栗宝一脚踩上去——**身体像被重新上了一次发条**：翅膀又能撑了，还能再蹬一次。它试着连起来：**飘 → 踩 → 再飘 → 等一拍 → 再踩 → 落上塔基**。栗宝不再是「飘过去」，它是**一节一节爬上去**的。
- **段 3 · 看清那层壳**：站上三层塔的塔顶，栗宝抬头——墨色的星穹**近到能看见纹路**了。那不是天空的云纹，是**一层壳上的裂缝**。空气稀薄得几乎吸不到，可它第一次确定：**上面是有东西的，而且那东西是可以被穿透的**。

> **ascend 弧此处 = 看见了顶，也看见了它是可以被穿透的**（3-6「破穹」的直接铺垫）。情绪是**吃力的攀登**，不是压迫。

## 2. 关卡定位：高压前奏 · **链式轴**（一关一轴）

| 定位 | 内容 | MDA 映射 |
|---|---|---|
| **教学（primary）** | **踩踏重置下落段 → 滞空可以「续」**。把 3-1 S3 的「羽降 + 踩踏」从一次组合扩成**一串**：`glide → 踩 du_fu → glide → 等相位 → glide → 踩 du_fu → 落塔`。`du_fu`×5（本章踏板峰，**y=120 恰在羽降主带**）是本关的骨架 | M：glide × stomp × beat；D：**链条规划**（先看完整条链再起跳）；A：Challenge + Fellowship（借光精灵的力） |

### 4.3 链条时序推算（踩踏为什么能「续」）

引用 `physics-config.json` + 3-2 §4.5 的实测事实：

- **单段羽降的水平续航**：羽降为 `140/140` 的 **45° 斜降（1:1）**。从满跳顶点（起跳点上方 ≈119px）开始羽降，可换来 ≈119px ≈ **3.7 格**的水平位移，加上上升段位移 → 同高（Δ0）总射程 ≈6 格（安全值 5.0）。
- **踩踏的作用**：`stompBounce=-300` 触发时，① 竖直速度被重置为 −300（**下落段归零**）；② **二段跳（`airJumps=1`）恢复**；③ 因而**羽降可以重新激活**（`glideActivateVy=60` 需要下落段）。→ **一次踩踏 ≈ 归还一整套「跳 + 飘」预算**。
- **踩踏不抬升**：−300 的初速在 `gravity=1800` 下只抬 `300²/(2×1800) ≈ 25px`。→ **踩踏换来的是「再飘一段」，不是「再高一层」**。这是本关反直觉但必须教会的一点，也是层3 只能靠 `bp_e2` 的原因。
- **链条上限（防主导策略）**：由于相邻 `du_fu` 间距 ≥3 格（本关 5/13/6/6 格），玩家**无法**用 du_fu→du_fu 连踩把自己一路送到关底。链条必须**混合**踏板与节拍台 → **摆位即上限**，无需新增任何规则或代码。
