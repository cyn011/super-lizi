## 1. 关名与叙事节拍

**关名：《陨雨回廊》**（主计划 §9 拍板项 ④ 已定；备选《炮雨星廊》《流火长廊》）

> **命名互文**：与 Ch2 的 **2-4《剪影回廊》** 刻意成对——同为「回廊」，一暗一亮、一逼仄一开阔。2-4 的回廊是**看不清**（剪影），3-4 的回廊是**看得太清**（陨雨劈头盖脸）。

### 1.1 在 ascend 弧线上的位置

| 弧线段 | 关 | 一句话 |
|---|---|---|
| 发现 | 3-1 | 「我能慢下来了」 |
| 尺度 | 3-2 | 「这地方比我想的大得多」 |
| 上行 | 3-3 | 「星界在呼吸；踩着它的节拍，我第一次真的往上了一层」 |
| **阻力** | **3-4《陨雨回廊》** | **「星界不欢迎我。慢下来，就成了靶子」** |
| 极限 → 突破 | 3-5 / 3-6 | 3-5 同批 B；3-6 批 C |

**叙事节拍（三段，承接 3-3 段 3「墨色星穹好像近了一点点」）**

- **段 1 · 被瞄准**：栗宝踩着节拍爬高了一层，正得意——头顶那块「星星」忽然亮了一下，然后**朝它飞了过来**。不是流星，是**朝着它来的**。这是栗宝第一次意识到：星界里有东西**在看它**，而且不欢迎它。
- **段 2 · 翅膀变成累赘**：它下意识撑开翅膀想躲——结果慢悠悠飘在半空，第二发、第三发不紧不慢地追上来。翅膀第一次不是救命的，是**要命的**。「浮」在这里的意思变了：**滞空 = 暴露**。
- **段 3 · 学会收翅**：它试着**不撑翅膀**，直直摔下去，砸在下一块窄得只有一步宽的浮岩上——**炮弹从它头顶擦过去了**。栗宝学会了这一关唯一要学的事：**不是不能飘，是只能飘刚刚好那么久**。

> **ascend 弧此处 = 阻力出现，上升第一次有敌意**。这一关的情绪是**压迫与克制**，不是律动。

**校验结论（代价轴）**
1. 全部 10 处跨越 `gap ≤` 对应安全值 ✅；最大 gap = **4**（#8 / #9），最大裕度消耗 4/5 = 80%。
2. 全部上升跨越 ≤3 格 ✅（唯一一处 = #2，恰为 3）。
3. 无 `Δ<0 且 gap>3` 的跨越 ✅。
4. **必需 glide 的跨越只有 2 处（#8 / #9）**，且均备第二解（du_fu 踩踏 / 地面绕行）✅ —— 这是**刻意的低值**：代价轴的命题是「**该飘的时候才飘**」，若必需 glide 处处皆是，玩家就学不会「收翅」。
5. **反向教学的关键在 #3**：gap 3 同时低于「羽降安全值 5.0」与「无羽降安全值 3.5」→ **两种打法都过得去**，但炮口（tx15，x=480）正压在跨越中段上方 28px。**飘 = 在火线里多待 0.49s；快落 = 0.36s 穿过**。这是全关唯一一处「同一跨越、两种代价」的显式对照，是代价轴的教具原点。

### 4.3 代价窗口推算（滞空时长 vs 暴露时长）

引用主计划 §2.2 / 3-3 §4.3 的同一组事实：

- **同高（Δ0）跨越的下落段**：自由落体 ≈ `119px / 自由落速 ≈ 0.36s`；羽降被 `glideMaxFall=140` 钳制 → `119 / 140 ≈ 0.85s`。
- **代价 = +0.49s 的火线滞留**（≈ 3-3 用来「等相位」的同一笔时间预算，在本关变成**纯负债**）。
- **弹道网几何**：5 门炮全在 `y=100`；羽降轨迹主带 `y≈96~180`（起跳顶点 y≈9 → 落点 y≈128/160，其中 96~180 是 45° 斜降的主要停留带）。→ **羽降下降段与炮线高度带高度重合**。
- **地面主路对照**：玩家站地面时 y≈224，与炮线垂距 124px；炮朝玩家发射，弹道为**斜向下**，穿越时间更短、落点更易预读 → 「**不飘 = 少挨打**」在几何上成立，而非口头承诺。

> **设计断言（交 QA 验）**：在 S4 走廊（tx32..42）内，「全程不按住跳跃键」的通关方案，其**被弹次数应显著低于**「全程羽降」的方案。若实测不成立（例如炮弹预判过强导致快落也必中），则 §8.2 的代价轴命题失败 → 回退方案见附录 B·R2。
