## 1. 设计意图：洞穴主题为何选「鼓苞」作新压力点

**2-1 是项目首个"换主题 + 加新敌"双首关**——既要让玩家感知世界观从草原进入洞穴，又只能引入**一个**新机制（守 P1/P2/P3 支柱，避免认知过载）。

1. **主题契合（地生苞 vs 管道植物）**：洞穴 biome 是"岩壁包围、地面裂缝"的封闭空间，鼓苞从地面裂缝噗出的形态天然贴合"种子唤醒大地"世界观（GDD13 §7.2，地生苞、非任天堂管道植物）。相比草原开阔地，洞穴的"封闭 + 脚下裂缝"让**"读节奏 / 等窗口"**的张力更强——玩家被空间压缩，被迫正视脚下周期。
2. **填补旧敌空白**：4 旧敌（ci_li / chong_feng / du_fu / shi_pao）均无"缩回可踩窗口"。鼓苞引入**位置/时间双周期 + 缩回可踩窗口**，新增"等还是冲"的时序决策维度，而非单纯加难度。
3. **单一新元素原则**：本关 `beat.enabled=false` 且**不含任何 spring_pad / beatPlatforms**，与鼓苞的时序压力正交——玩家本关只学"鼓苞周期"一件事，不叠加弹跳/节拍双新机制（详见 content-spec §9）。`chong_feng` 亦有意省略，降低首洞穴关密度，让新元素被清晰看见。

## 2. 节奏曲线（难度递进段落）

> 难度整体略高于 1-2，但以**公平节奏**为主（鼓苞固定周期 + 前摇 telegraph），不构成"硬核突然死亡"。

| 段落 | x 范围（近似） | 主要内容 | 设计意图 |
|---|---|---|---|
| **引入** | 64–544 | 热身 coin/seed → 单苞教学（gb3，offset 0） | 在零其他压力下先记住"一个苞的周期"；用 DORMANT 安全窗让玩家安全通过，建立"可预测"的安全感 |
| **中段** | 576–1024 | 双苞交替走廊（gb8/gb9）+ 巡逻敌（du_fu/shi_pao/ci_li）+ 种子蜕变推进 | 把"单苞记忆"升级为"双苞相对相位"读取；mid 检查点（x1024）前给一次喘息 |
| **gauntlet** | 1120–1216 | 终前鼓苞 gauntlet（gb20/gb22，错相）+ gauntlet 前检查点（x1216） | 高潮时序考试：错相不再干净，逼玩家真正读相位而非背模式；前检查点防劝退 |
| **终点** | 1248–1344 | 种子余量 + 门前赏金 coin + 凯旋之门 | 缓降落幕，奖赏收集，节奏回落 |

曲线呈"**低—升—峰—落**"单峰：前 1/3 教学、中段练相位、后 1/3 加压、终点释放。检查点密度与 1-2 一致（2 个），不因新主题突然变硬核。

## 3. 难点设计说明：三处错相鼓苞的 timing 意图

鼓苞全部为**固定周期（T=2120ms，无 RNG）+ 可见前摇**，失败皆"公平"。难度来自**相位关系**而非随机。以下三处是相位设计的递进：

### 3.1 交替走廊（gb8 offset 0 / gb9 offset 1060）
- **1060ms = 正好半周期（T/2）**：gb9 与 gb8 完美反相——gb8 危险时 gb9 必在缩回/休眠（安全），反之亦然。形成"一上一下"走廊。
- **意图**：用最低风险（走廊内无其他威胁）教会玩家"苞不一定同步"，必须**同时追踪两个独立周期**再找间隙穿过。这是后续 gauntlet 的"预练习"，但代价极低。

### 3.2 gb9（x544，offset 1060）作为走廊后半拍
- 与 gb8 配对后，玩家学到的可过关窗口是"当 one 危险时 slip 过 the other"。gb9 自身仍是半周期错相，**安全窗宽、可预测**，所以即使首次遇到双苞，也不会因"差一帧"卡死（RETRACTING 窗口边界可踩，GDD13 §5 边界处理）。

### 3.3 gb22（x1184，offset 530）作为 gauntlet 的"不规则"后半拍
- **530ms = 正好四分之一周期（T/4）**：gb22 落后 gb20（offset 0）约四分之一周期，二者**不再干净反相**。推导危险窗（按 T=2120 折算）：gb20∈[1100,1960)ms，gb22∈[570,1430)ms，二者重叠约 [1100,1430) 共 **~330ms 双苞同时危险**，且安全间隙变窄、不对称。
- **意图**：打破"半周期可背"的错觉。玩家在走廊学到的"干净交替"在 gauntlet 失效，必须**实时读相位**才能找到变窄的通过窗。难度上升来自相位非对称，而非随机或瞬杀（守 GDD07 非瞬杀 + 公平失败）。

> 三处落点形成"教学(干净半周期) → 巩固(走廊) → 考试(不规则四分之一周期)"的相位难度梯度。

## 4. 种子蜕变触发节奏（seed_01–04 沿 x 升序走完四阶段）

- **排布逻辑**：6 颗种子按通关路径 x 升序排布，前 4 颗 `seed_01(192)→seed_02(416)→seed_03(608)→seed_04(960)` 恰为玩家一局内自然可达顺序。按 GDD12 §3.3 `growthPerSeed=0.25`，每颗 +0.25，4 颗即满蜕变：苗(sprout)→藤(vine)→花(bloom)→果(fruit)。
- **为何 x 升序**：让蜕变阶段由**关卡地理决定**（非 RNG），设计可依赖"玩家到达 Y 点时已进化到 X 阶段"。果阶段（seed_04 @ x960）恰好落在 mid 检查点（x1024）**之前**——进入更难的半场前先给一个"你已长大"的视觉/情绪回报。
- **余量设计**：`seed_05(1088)`、`seed_06(1248)` 为收集探索余量，不强制四阶段；给了重玩/探索价值，却不会打乱主蜕变弧。

## 5. 与 1-1 / 1-2 的差异化

| 维度 | 1-1 / 1-2 | 2-1 |
|---|---|---|
| 主题 | 草原（outdoor，明亮） | **洞穴（cave，冷暗封闭）**——首个换主题关（GDD05 换色不换形） |
| 新敌 | 无新敌种（沿用 4 旧敌） | **首个新敌种 gu_bao**（唯一新机制，单一新元素原则） |
| 宽度 | 1-1=40 / 1-2=48 | 44（居中，洞穴单关长度） |
| 种子弧 | 未做单关四阶段刻意排布 | **首次把 6 种子按 x 升序排成 苗→藤→花→果 完整蜕变弧** |
| 难度/检查点 | 1-2 为前序峰值 | 略高于 1-2，公平节奏为主；检查点密度一致（2 个） |
| 节拍 | 均 `beat.enabled=false` | 同样 `false`，且**不引入 spring_pad**，避免与鼓苞时序双压 |

**一句话差异化**：2-1 是项目**首个换主题 + 首新敌**双首关，用"单一新机制（鼓苞）+ 完整种子蜕变弧"在不过载的前提下把时序压力与成长回馈同时推上新台阶。
