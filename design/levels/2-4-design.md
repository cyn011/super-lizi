## 1. 设计意图：为何「剪影」落 2-4 且选藤林

**2-4 是 World 2 收尾关**——在已引入鼓苞(2-1)/弹藤(2-2)/气旋(2-3) 三个新机制后，本关用一个**低成本、高识别度的敌种变体**收束章节，而非第四个全新机制（守 P1/P2/P3 支柱，避免认知过载）。

1. **变体而非新机制**：嘟浮剪影复用原嘟浮浮动数学，仅加一种行为扭曲（默认 A. 镜像分身），工程风险远低于新物理子系统；玩家已熟悉"浮空软顶敌"的手感，本关只需学会"读镜像反相"。
2. **主题契合（剪影 vs 亮背景）**：选 **vine_forest（藤林）** 因其**亮背景**（天空 `#5BC8F5` / 草绿 `#7CC242`）让暗色剪影（`描边 #2A1A12`）**高亮度对比**——直接满足 GDD16 §7.4「剪影必须可区分、防认知混淆」的可访问性硬要求。若选 cave（暗背景 `#1C2E49`）暗剪影会融入背景，违反 art-bible §3.3 对比红线。
3. **「剪影回廊」核心循环**：3 对"光嘟浮 + 暗剪影"反相浮动，构成一条**成对镜像的空中走廊**——玩家须读"一个升、一个落"的对称关系找间隙通过或踩杀。这是「剪影回廊」命名的由来，也是本关唯一新挑战维度。
4. **差异化 2-2（同为 vine_forest）**：2-2 的核心是**弹藤垂直越障**（靠弹起够高位）；2-4 刻意**不强制高位**（所有 seed/coin 落地面 y=200），聚焦**空中镜像读图**——两者同主题但玩法身份不同，避免玩家觉得"又是一关弹藤"。

## 2. 节奏曲线（难度递进段落）

> 难度整体略高于 2-3，但以**镜像读图为主**（成对反相浮动的对称解谜），不构成"硬核突然死亡"。

| 段落 | x 范围（近似） | 主要内容 | 设计意图 |
|---|---|---|---|
| **引入** | 64–560 | 热身 coin/seed → 教学镜像对（Pair1 #2/#3） | 在零其他压力下先记住"一对光/暗反相浮动"；剪影带暖黄边 + 反向翅，与光嘟浮一眼可分 |
| **中段** | 624–928 | 第二镜像对（Pair2 #8/#9）+ 地面/高位威胁（ci_li/shi_pao）+ 种子蜕变推进 | 把"单对记忆"升级为"边躲地面敌边读空中镜像"；mid 检查点（x928）前给喘息 |
| **gauntlet** | 1024–1376 | 第三镜像对（Pair3 #17/#18，考试"读双反相"）+ gauntlet 前检查点（x1376） | 高潮：镜像对 + 高位石炮 + 地面刺球叠加，逼玩家实时读双反相；前检查点防劝退 |
| **终点** | 1320–1408 | 种子余量 + 门前赏金 coin + 凯旋之门 | 缓降落幕，奖赏收集，节奏回落 |

## 3. 难点设计说明：三对镜像的读图意图

剪影全部为**固定反相（mirrorOffset=π，无 RNG）**，失败皆"公平"。难度来自**配对关系**而非随机。以下三对是读图难度的递进：

### 3.1 教学对（Pair1 #2/#3，x176/240）
- 剪影与光嘟浮**严格反相**：剪影在顶时光体在底，反之亦然，二者 `vy` 恒反号。
- **意图**：用最低风险（无其他空中威胁）教会玩家"暗的不是无害阴影，它和光体是一对在反相跳"；用暖黄发光边 + 反向翅确保不误判。

### 3.2 第二对（Pair2 #8/#9，x560/624）
- 加入 `ci_li`（地面 #6）+ `shi_pao`（高位 #11）协同，玩家须**同时读空中镜像与地面/高位威胁**。
- **意图**：把"单对读图"升级为"多轨注意"，但仍克制（仅 1 对镜像 + 2 地面/高位敌）。

### 3.3 第三对（Pair3 #17/#18，x1024/1088，gauntlet）
- 叠加 `shi_pao`（高位 #21）+ `ci_li`（地面 #14 已前置）+ 门前高密度，镜像对成为"终前考试"。
- **意图**：镜像读图 + 多威胁并发，考验玩家是否真正把"反相"内化成肌肉记忆；难度上升来自并发而非随机或瞬杀（守 GDD07 非瞬杀 + 公平失败）。

> 三对落点形成"教学(单对) → 巩固(加地面威胁) → 考试(并发)"的镜像读图梯度。

## 4. 种子蜕变触发节奏（seed_01–04 沿 x 升序走完四阶段）

- **排布逻辑**：6 颗种子按通关路径 x 升序排布，前 4 颗 `seed_01(304)→seed_02(688)→seed_03(880)→seed_04(1152)` 恰为玩家一局内自然可达顺序。按 GDD12 §3.3 `growthPerSeed=0.25`，每颗 +0.25，4 颗即满蜕变：苗(sprout)→藤(vine)→花(bloom)→果(fruit)。
- **为何 x 升序**：让蜕变阶段由**关卡地理决定**（非 RNG），设计可依赖"玩家到达 Y 点时已进化到 X 阶段"。果阶段（seed_04 @ x1152）恰好落在 mid 检查点（x928）**之后**、gauntlet 之前——进入更难半场前先给"你已长大"的视觉/情绪回报。
- **余量设计**：`seed_05(1320)`、`seed_06(1200)` 为收集探索余量，不强制四阶段；给了重玩/探索价值，却不会打乱主蜕变弧。
- **本关差异化**：所有种子落**地面 y=200**（不强制高位），把注意力留给空中镜像读图，与 2-2（种子常落 oneway 高位需弹藤）明确区分。

## 5. 与 2-2 的差异化

| 维度 | 2-2 藤林 | 2-4 剪影回廊 |
|---|---|---|
| 新元素 | 弹藤（垂直越障） | **嘟浮剪影（镜像读图）** |
| 核心动词 | 踩/弹/够（垂直） | 读/踩/避（反相对称） |
| 种子位置 | 常落 oneway 高位（需弹藤） | **全落地面**（聚焦空中读图） |
| 敌种重心 | bouncy_vine×4 + 旧敌 | **du_fu_silhouette×3 + du_fu×3（镜像对）** + ci_li/shi_pao |
| 主题复用 | vine_forest（首用） | vine_forest（复用，亮背景托剪影） |
| 难度/检查点 | 略高于 2-1 | 略高于 2-3，镜像读图为主；检查点密度一致（2 个） |
| 节拍 | 均 `beat.enabled=false` | 同样 `false`，且**不引入弹藤/气旋**，避免与剪影双新机制 |

**一句话差异化**：2-4 是 World 2 收尾关，用一个**暗色镜像变体（剪影）**在已熟悉的藤林里把"浮动"升级为**成对反相读图**，不引入第四个新机制、不堆垂直越障，在不过载的前提下把镜像解谜推上章节峰值。
