## 1. 设计意图：藤林主题为何选「弹藤」作新压力点

**2-2 是项目第 2 个"换主题 + 加新元素"关**——延续 2-1（洞穴+鼓苞）的"单新元素原则"，本关换到明亮藤林，只引入**弹藤**一个全新机制。

1. **主题契合（草藤 vs 蘑菇弹簧）**：藤林 biome 是"植被包裹、向上生长"的开放空间，弹藤（草藤线圈）从地面弹起玩家的形态天然贴合"种子唤醒大地"世界观（GDD14 §7.2，草藤线圈、非任天堂蘑菇弹簧）。相比洞穴封闭，藤林用**高台 + 向上弹起**让"垂直越障"张力更强——玩家被空间鼓励向上看。
2. **填补旧敌空白**：4 旧敌 + 鼓苞均无"把玩家高高弹起"机制。弹藤引入**垂直弧线规划**新维度（"踩/弹/够"），而非单纯加难度。
3. **单一新元素原则**：本关 `beat.enabled=false` 且**不含任何 cyclone / gu_bao / beatPlatforms**，与弹藤的垂直压力正交——玩家本关只学"弹藤弹起 + 落点规划"一件事（详见 content-spec §8）。`chong_feng` 亦有意省略（水平冲锋与垂直主题协同弱），让新元素被清晰看见。

## 3. 难点设计说明：三处弹藤的意图递进

弹藤全部为**确定性弹起（无 RNG）+ 可预测高度**，失败皆"公平"。难度来自**高度/落点规划**而非随机。以下三处是垂直难度的递进：

### 3.1 教学弹藤（idx2，normal -680≈4tile）
- 紧接出生点，零威胁；玩家踩上被弹起 ≈4 tile，落点正好是 oneway(5,6)@ty3 高台（seed_01）。建立"弹藤 = 向上工具"的安全感，且**首次揭示垂直必要性**（seed_01 离地 ~4.5 tile，单/二段跳不可及）。
- 意图：用最低风险教会"踩→弹→落高台"闭环。

### 3.2 中段机动弹藤（idx8，normal）
- 置于敌群（du_fu/shi_pao/ci_li）之间，作为**垂直机动点**而非解谜：玩家可借它快速升空闪避 shi_pao 弹丸或越过 ci_li。难度温和，强化"弹藤是通用机动"认知。

### 3.3 强档考试弹藤（idx17，strong -816≈5.1tile）
- **strong 档**使弹起 ≈5.1 tile，叠加二段跳可达 ty4 高台（idx18 高位 coin，约 5.6 tile）。这是本关**唯一要求"弹藤+二段跳"链式操作**的点——玩家若只弹不二段，差一点够不到；必须主动规划"弹起顶点再二段"。
- 意图：打破"弹藤=无脑高"的错觉。玩家在教学/中段学到的"普通弹起"在考试失效，必须**实时算链弧**才能拿高位赏金。难度来自弧线非对称，而非随机或瞬杀（守 GDD07 非瞬杀 + 公平失败）。

> 三处落点形成"教学(normal 够高台) → 巩固(机动) → 考试(strong+二段链弧)"的垂直难度梯度。

## 4. 种子蜕变触发节奏（seed_01–04 沿 x 升序走完四阶段）

- **排布逻辑**：6 颗种子按通关路径 x 升序排布，前 4 颗 `seed_01(176,高位)→seed_02(416)→seed_03(544)→seed_04(864)` 恰为玩家一局内自然可达顺序。按 GDD12 §3.3 `growthPerSeed=0.25`，每颗 +0.25，4 颗即满蜕变：苗(sprout)→藤(vine)→花(bloom)→果(fruit)。
- **为何 seed_01 高位**：把"第一颗种子"放在弹藤教学高台上，让玩家**第一次蜕变（苗）就与弹藤绑定**——强化"藤林=生长+向上"的主题呼应（P3 蜕变支柱）。
- **果阶段落点**：seed_04(864) 落在 mid 检查点(928) **之前**——进入更难的半场前先给"你已长大"的视觉/情绪回报（同 2-1 设计）。
- **余量设计**：`seed_05(1056)`、`seed_06(1312)` 为收集探索余量，不强制四阶段；给了重玩/探索价值，却不会打乱主蜕变弧。

## 5. 与 2-1 / 1-1 / 1-2 的差异化

| 维度 | 1-1 / 1-2 | 2-1（洞穴） | 2-2（藤林） |
|---|---|---|---|
| 主题 | 草原（grass） | 洞穴（cave，冷暗） | **藤林（vine_forest，明亮绿系）**——换色不换形 |
| 新元素 | 无新敌种 | 鼓苞（危害时序） | **弹藤（纯辅助垂直越障）**——角色互补（危害 vs 辅助） |
| 垂直机制 | 跳/二段跳（≤3.6tile） | 无新增垂直 | **弹藤（≈4tile，+二段≈5.6tile）** 引入垂直弧线规划 |
| 宽度 | 1-1=40 / 1-2=48 | 44 | 46（章节略长） |
| 种子弧 | 1-2 刻意四阶段 | 完整四阶段（x 升序） | **完整四阶段 + seed_01 高位绑定弹藤教学** |
| 难度/检查点 | 1-2 前序峰值 | 略高于 1-2，公平节奏 | 略高于 2-1，垂直越障为主；检查点一致（2 个） |
| 节拍 | 1-1/1-2 部分启用 | `false`（不组合鼓苞） | 同样 `false`，不组合弹藤外新机制 |

**一句话差异化**：2-2 是项目**第二个换主题 + 新元素**关，用"单一新机制（弹藤·纯辅助垂直越障）+ 完整种子蜕变弧 + 高台垂直必要性"在不过载的前提下把垂直规划 mastery 推上新台阶，与 2-1 的"危害时序"形成角色互补。
