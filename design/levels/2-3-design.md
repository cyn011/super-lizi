## 1. 设计意图：风暴天空主题为何选「气旋」作新压力点

**2-3 是世界 2 的收官关**——延续"单新元素原则"，换到阴沉风暴天空，只引入**气旋**一个全新机制（与 2-1 鼓苞、2-2 弹藤形成世界 2 的"三新元素"递进）。

1. **主题契合（升叶旋风 vs 任天堂机关）**：风暴天空 biome 是"悬浮岩台、上升气流"的开放垂直空间，气旋（卷着落叶上升的半透明气柱）把玩家托起的形态天然贴合"风唤醒生长"世界观（GDD15 §7.2，升叶旋风、非任天堂机关）。相比藤林向上生长，风暴天空用**持续上升气流**让"垂直气控"张力更强——玩家须主动控横移、择机离场。
2. **填补旧敌空白**：4 旧敌 + 鼓苞 + 弹藤均无"持续反向力场"。气旋引入**持续垂直气控**新维度（"乘/控/离"），而非单纯加难度。
3. **单一新元素原则**：本关 `beat.enabled=false` 且**不含任何 bouncy_vine / gu_bao / beatPlatforms**，与气旋的垂直压力正交——玩家本关只学"乘气流 + 控横移脱离"一件事（详见 content-spec §8）。`ci_li` 亦有意省略（地面刺球与垂直主题协同弱），让新元素被清晰看见。

## 3. 难点设计说明：三处气旋的意图递进

气旋全部为**确定性力场（无 RNG）+ 可规避**，失败皆"公平"。难度来自**气控精度**而非随机。以下三处是垂直难度的递进：

### 3.1 教学气旋（idx2，liftAcc 2600 / riseMax 220）
- 紧接出生点，零威胁；玩家走入气柱被持续托起（净向上 +800 px/s²，钳 220），落点正好是 oneway(5,6)@ty3 高台（seed_01）。建立"气旋 = 持续上升工具"的安全感，且**首次揭示垂直必要性**（seed_01 离地 ~4.5 tile，单/二段跳不可及）。
- 与弹藤关键差异（设计强调）：弹藤是**一次性弹起**（落地触发、高度固定）；气旋是**持续托起**（进入即升、保留横移、须主动脱离）。教学气旋让玩家体会"在气流里我仍能左右控"——这是后续考试的基础。

### 3.2 中段机动气旋（idx8）
- 置于敌群（du_fu/chong_feng/shi_pao）之间，作为**垂直机动点**而非解谜：玩家可借它快速升空闪避 shi_pao 弹丸或越过 chong_feng。难度温和，强化"气旋是通用机动"认知。

### 3.3 考试气旋（idx13）
- 落点 (22,23)@ty3 高位 coin(14)，须**乘气流托到柱顶 + 控横移落到窄高台**。这里玩家不能"无脑站气流"——气流托到柱顶后须**主动横移脱离**落到旁边高台，否则会随气流循环或出柱下落。难度来自"托起 + 横移落点"的协同，而非随机或瞬杀（守 GDD07 非瞬杀 + 公平失败）。

> 三处落点形成"教学(持续托起够高台) → 巩固(机动) → 考试(托起+横移落点)"的垂直难度梯度，与 2-2 弹藤的"弹起+二段链弧"形成**同主题（垂直）异手法（一次性 vs 持续）**的互补。

## 4. 种子蜕变触发节奏（seed_01–04 沿 x 升序走完四阶段）

- **排布逻辑**：6 颗种子按通关路径 x 升序排布，前 4 颗 `seed_01(176,高位)→seed_02(416)→seed_03(544)→seed_04(864)` 恰为玩家一局内自然可达顺序。按 GDD12 §3.3 `growthPerSeed=0.25`，每颗 +0.25，4 颗即满蜕变：苗(sprout)→藤(vine)→花(bloom)→果(fruit)。
- **为何 seed_01 高位**：把"第一颗种子"放在气旋教学高台上，让玩家**第一次蜕变（苗）就与气旋绑定**——强化"风暴=风唤醒生长"的主题呼应（P3 蜕变支柱）。
- **果阶段落点**：seed_04(864) 落在 mid 检查点(928) **之前**——进入更难的半场前先给"你已长大"的视觉/情绪回报（同 2-1/2-2 设计）。
- **余量设计**：`seed_05(1056)`、`seed_06(1312)` 为收集探索余量，不强制四阶段；给了重玩/探索价值，却不会打乱主蜕变弧。

## 5. 与 2-1 / 2-2 的差异化

| 维度 | 2-1（洞穴·鼓苞） | 2-2（藤林·弹藤） | 2-3（风暴·气旋） |
|---|---|---|---|
| 新元素角色 | 鼓苞（危害·时序） | 弹藤（辅助·一次性弹起） | **气旋（辅助·持续托起）** |
| 垂直机制 | 无新增垂直 | 弹藤 ≈4tile（一次性） | **气旋持续托起（保留横移）** |
| 主题 | 洞穴（cave，冷暗） | 藤林（vine_forest，绿系） | **风暴天空（storm_sky，蓝系）** |
| 敌组合省略 | chong_feng | ci_li | ci_li |
| 宽度/parTime | 44 / 72000 | 46 / 76000 | 46 / 78000 |
| 种子弧 | 完整四阶段 | 完整四阶段 + seed_01 高位绑弹藤 | **完整四阶段 + seed_01 高位绑气旋** |
| 节拍 | `false` | `false` | `false` |

**一句话差异化**：2-3 是世界 2 收官关，用"单一新机制（气旋·持续垂直气控）+ 完整种子蜕变弧 + 高台垂直必要性"在不过载的前提下把垂直气控 mastery 推上新台阶，与 2-1（危害时序）/ 2-2（一次性弹起）形成"世界 2 三新元素"的垂直维度递进。
